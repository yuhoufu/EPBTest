# V2.14.2.0 正式包快捷部署说明

> 快捷部署修订：`QUICKDEPLOY_R9`
>
> 发布方式：正式包直接安装。软件不审批现场发布状态，实际运行、停用与验收由操作人员决定。
>
> 交付压缩：本机 7-Zip Ultra/LZMA2 固实压缩；优先传输 `.7z` 与配套 `.7z.sha256`。

## 最短操作

1. 退出旧版试验程序，确认所有卡钳、液压、AO 和程控电源已经 OFF。
2. 将 `.7z` 复制到远程工控机本地磁盘，用 7-Zip 完整解压；不要在压缩包内或网络共享目录直接运行。
3. 使用以后长期运行试验的 Windows 账号登录。
4. 双击 `一键安装正式版.cmd`，接受管理员权限提示。
5. 显示安装成功后，双击桌面的 `MT EPB 试验系统 V2.14`。

不需要手动启动 Watchdog、SessionAgent 或 SafetyAgent。

## 包内文件

```text
一键安装正式版.cmd     检查必要程序存在后直接安装
一键修复.cmd           修复服务、登录任务、ACL、程序目录和快捷方式
一键卸载.cmd           卸载服务和任务，终止安装目录内的 SessionAgent
启动试验.cmd           启动已安装的主程序
检查运行状态.cmd       查看服务、Agent、主程序状态及各进程实际路径
QuickDeploy-Installer.ps1 经外层哈希保护的安装/修复/卸载入口
Package\               由操作人员选择和管理的程序目录
快捷部署包-SHA256.txt  可选的传输核对信息，不参与运行门禁
```

## 安装后的正常状态

运行 `检查运行状态.cmd`，应看到：

```text
监督服务：Running
登录代理：Running 或 Ready
```

安装目录固定为：

```text
C:\Program Files\MTTFTest\Current
```

服务和日志：

```text
服务：MTTFTestSupervisor
登录任务：MTTFTestSessionAgent
C:\ProgramData\MTTFTest\Supervisor\
C:\Users\<当前用户>\AppData\Local\MTTFTest\SessionAgent\
```

## 已取消的版本和包验证

- 安装、启动、恢复和关闭都不再校验版本号、`releaseStatus`、`deploymentApproved` 或 `gitDirty`。
- 不再校验逐文件 SHA256、`build-identity.json`、DPAPI 槽描述或槽指针。
- `Config\TestConfig.xml` 是运行时可写配置，修改后不会再被判定为程序包损坏。
- 主程序仍可记录版本、Git 和哈希信息供追溯，但这些信息只写日志，不作裁决。
- 使用哪个版本、是否回退、是否继续运行和如何验收，均由操作人员负责。

## 仍保留的安全底线

以下逻辑仍保留，因为它们直接关系到设备和进程安全，不属于版本管理：

- 安装时只检查主程序、Watchdog、SessionAgent、SafetyAgent 和协议 DLL 是否存在。
- Supervisor 仍核对当前请求进程、PID/启动时间、工作目录和会话参数，防止双进程误接管。
- 任意恢复都必须先完成断电回读、旧进程退出证明和单实例接管。
- 确认的卡钳、液压或电路硬件故障仍保持最小域隔离，不自动重新上电。
- 无法形成物理断能或设备安全证明时仍会停止运行，但不会因为版本或包哈希阻断。

## 日常注意事项

- 建议复制整个部署包，以免缺少运行依赖；软件不再判断组件版本是否一致。
- 安装时使用的账号必须是以后长期登录的生产账号。
- 无人值守期间可以断开远程桌面，但不要注销 Windows 用户。
- 不要连续双击主程序，不要手工结束 Supervisor、SessionAgent 或 SafetyAgent。
- 项目配置允许由程序正常写入；替换程序文件和选择版本由操作人员自行管理。
- 出现恢复窗口时等待自动处理；人工静音只关闭蜂鸣器，故障灯和锁存仍保持。

## 故障处理

安装失败：保存命令窗口内容。若提示缺少必要组件，应补齐整个程序目录。

服务异常：运行 `一键修复.cmd`。

需要停止使用：先在主程序安全停止，再运行 `一键卸载.cmd`。卸载会停止并注销登录任务，同时终止安装目录内已经运行的 SessionAgent；不会按名称误杀其他目录的进程。

查看状态：运行 `检查运行状态.cmd`。
