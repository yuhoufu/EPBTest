# MT EPB 试验系统快捷部署与卸载说明

> 快捷部署修订：`QUICKDEPLOY_R11`
>
> 正式 7z 已自带本说明和全部维护脚本；必须完整解压后使用。

## 操作员首次运行

1. 将 `.7z` 复制到远程工控机本地磁盘并完整解压，不能在压缩包或网络共享目录中直接运行。
2. 使用以后长期运行试验的 Windows 账号登录。
3. 双击解压目录第一层的 `一键安装正式版.cmd`。
4. Windows 管理员权限提示出现后选择“是”。
5. 脚本自动复制程序到 `C:\Program Files\MTTFTest\Current`，配置 Supervisor、SessionAgent、主程序登录自启动及桌面快捷方式。

安装成功后，使用桌面快捷方式或 `启动试验.cmd` 启动程序，不需要手动启动 Watchdog、SessionAgent 或 SafetyAgent。

## 程序更新

1. 在旧程序中停止试验，确认设备断能后完全退出主程序。
2. 完整解压新版本到一个新的本地目录。
3. 双击新目录第一层的 `一键安装正式版.cmd` 并接受管理员权限提示。
4. 程序自动停止旧后台组件、替换 `Current`、重新配置自启动并启动新版本。

不要把新文件手工覆盖到正在运行的 `Current` 目录。

## 自动配置内容

- 固定程序目录：`C:\Program Files\MTTFTest\Current`
- 监督服务：`MTTFTestSupervisor`
- 登录代理任务：`MTTFTestSessionAgent`
- 主程序登录自启动任务：`MTTFTestAutoStart`（登录后延迟 15 秒）
- 桌面快捷方式：`MT EPB 试验系统 V2.14`

注销或重启 Windows 后，使用同一生产账号登录，主程序会自动启动。断开远程桌面但不注销不会影响运行。

## 维护入口

正式包根目录提供以下入口：

```text
一键安装正式版.cmd   手工重新安装
一键修复.cmd         修复服务、任务、权限和快捷方式
一键卸载.cmd         完整删除程序、服务、任务和快捷方式
检查运行状态.cmd     查看相关进程、任务、服务及实际路径
启动试验.cmd         启动已安装的主程序
快捷部署说明.md       当前操作说明
```

## 卸载旧程序

1. 在主程序中安全停止试验，确认设备断能和数据落盘完成，然后完全退出程序。
2. 从任一完整解压的正式包中双击 `一键卸载.cmd`。
3. 接受管理员权限提示；核对警告后输入 `Y` 确认。
4. 看到“卸载完成”后，程序目录、服务、计划任务和快捷方式均已删除。

卸载会删除 `C:\Program Files\MTTFTest`，但保留 `C:\ProgramData\MTTFTest` 中的现场配置、日志和事故证据。需要清除这些运行数据时应由维护人员另行备份和处理，不由快捷卸载自动删除。

重新安装时，完整解压最新版 7z，再运行其中的 `一键安装正式版.cmd`。原有 ProgramData 配置会继续使用。

## 仍保留的安全底线

- 首次配置只检查主程序、Watchdog、SessionAgent、SafetyAgent 和协议 DLL 是否齐全。
- 版本号、配置文件哈希和发布审批状态不参与现场启动裁决。
- Supervisor 仍核对进程 PID、启动时间、工作目录和会话参数。
- 自动恢复前仍必须完成设备断能、旧进程退出证明和单实例接管。
