# V2.16.0.0 正式版 QUICKDEPLOY R28

本包为干净源码构建的正式版本（FORMAL_RELEASE）。真实 NI/CAN/电源/液压和连续 168 小时现场验证仍待用户执行，不能根据“正式版”字样推断这些项目已经通过。

## 安装与升级

1. 整包解压到本地，保留外层快捷入口与内层 Package，禁止在压缩软件里直接运行。
2. 旧程序先停止试验，再运行“一键停止全部相关进程.cmd”。安全受阻时保留安全组件工作，检查真实电机、电源和压力。
3. 双击“一键安装正式版.cmd”并接受管理员提权。需要 .NET Framework 4.8 与 x86 NI-DAQmx；远程电脑不需要 Visual Studio、Python 或 PowerShell 7。
4. 默认安装在 Program Files (x86)\MTTFTest\Current，现场配置在 %ProgramData%\MTTFTest\Config。全文件哈希核验；同版本不同内容必须换包。旧程序保存在 .retired-*；中断后重跑安装或修复。生产数据不删除。
5. 安装不开始机械试验。“启动试验.cmd”沿用旧入口名，仅打开应用；确认项目、六通道、压力/电流/电源映射和剩余次数后，由操作人员开始。

旧 schema 5/6 检查点只迁移业务剩余正式圈，运行许可、nonce、会话不迁移。机械次数与正式圈保持不同口径，不覆盖历史数据。旧检查点缺少安全证明时安装受阻；现场已完成物理断能隔离后，工程人员才可运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\QuickDeploy-Installer.ps1 -Mode Install -SourceDirectory .\Package -PhysicalIsolationConfirmed
```

该参数记录人工隔离确认，不伪造硬件回执。V3 EngineHost/Kernel 不得混装；V3 降级需另行迁移，不能直接覆盖。

## 清场与恢复

“一键停止全部相关进程”仅处理明确安装根中的主程序、Watchdog、SessionAgent、SafetyAgent 及该根遗留的 EngineHost。先持久禁止新主程序拉起、停用登录任务、请求安全关闭，等待本次准确 PID/启动时间的完整断能与落盘回执，再结束后台。不会全机按名称盲杀。

默认等待 45 秒。返回 10 表示安全受阻（保留安全接管）；20 表示身份不明；30 表示后台操作失败；40 表示进程残留。非零均未报告清场成功。状态与结果保存在 %ProgramData%\MTTFTest\maintenance-inhibit.json 和 last-maintenance-result.json。

仅当操作人员实际确认物理隔离后，才可用 Stop-RelatedProcesses.ps1 -Mode Stop -PhysicalIsolationConfirmed 完成受阻清场。该记录明确区分人工隔离与软件断能证明。

“恢复后台服务.cmd”在清场完成和正式包校验后恢复服务/任务、封存旧会话，保持试验待机。不手工删除维护文件。另一个便携安装需通过 -InstallRoot 明确指定，目录末级应为 MTTFTest。-Mode Status 只读，-WhatIf 不修改状态。

## 采证、验证与回退

“一键故障采证.cmd”在当前账户桌面生成包身份、监督状态、退出回执、进程和 Windows 应用错误。可加 -ProjectDirectory 'D:\EPB_Data\项目目录' 收集项目 Logs/Recovery/WatchdogSessions。单文件上限 20 MiB、总计 256 MiB；跳过或读取失败写入 evidence-index.json。完整数据库与原始大日志仍按现场封盘工具保存。

按“现场验证记录模板.md”执行启停、故障恢复、数据对账和 168 小时运行。每次失败保存 bundle-identity.json、Package\build-identity.json、故障事务 ID、时间和封盘目录。

回退前安全停机、采证并备份 ProgramData 配置和项目检查点。优先恢复同 V2.16 家族的已验证包；.retired-* 用于人工回退审计。V2.14.2.11 是工程回退基线，不自动成为 LastKnownGood。跨代回退不得复用活动许可或覆盖生产数据。
