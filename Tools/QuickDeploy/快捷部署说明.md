# V2.14.1.0 快捷部署说明

> 包状态：`FIELD_CANDIDATE_PENDING_168H`
> 快捷部署修订：`QUICKDEPLOY_R6`（修复正式槽封印、现场候选身份识别和安装后文件集校验）
>
> 用途：远程工控机现场候选安装与实机验证
> 操作复杂度：复制整个文件夹，双击一次安装，之后从桌面启动

## 最短操作步骤

1. 退出旧版试验程序，并确认所有卡钳、液压、AO 和程控电源已经 OFF。
2. 将整个快捷部署包复制到远程工控机本地磁盘；不要从网络共享目录直接运行。
3. 使用以后长期运行试验的 Windows 账号登录。
4. 双击 `一键安装现场候选.cmd`，接受管理员权限提示。
5. 显示“安装成功”后，双击桌面的 `MT EPB 试验系统 V2.14`。

不需要手动启动 Watchdog、SessionAgent 或 SafetyAgent。

## 包内文件

```text
一键安装现场候选.cmd   安装并验证完整包
一键修复.cmd           修复服务、登录任务、ACL、双槽和快捷方式
一键卸载.cmd           卸载服务和任务，但保留程序、数据和事故证据
启动试验.cmd           启动已安装的主程序
检查运行状态.cmd       查看服务、Agent 和主程序状态
QuickDeploy-Installer.ps1 经外层哈希保护的安装/修复/卸载入口
Package\               不可拆分、不可单独替换文件的正式候选程序包
快捷部署包-SHA256.txt  外层传输校验
```

## 安装后的正常状态

运行 `检查运行状态.cmd`，应看到：

```text
监督服务：Running
登录代理：Running 或 Ready
```

安装目录固定为：

```text
C:\Program Files\MTTFTest\Current
```

服务和日志：

```text
服务：MTTFTestSupervisor
登录任务：MTTFTestSessionAgent
C:\ProgramData\MTTFTest\Supervisor\
C:\Users\<当前用户>\AppData\Local\MTTFTest\SessionAgent\
```

## 现场注意事项

- 必须复制整个部署包；禁止只复制 `MTTFTest.exe` 或某个 DLL。
- 安装时使用的账号必须是以后长期登录的生产账号。
- 无人值守期间可以断开远程桌面，但不要注销 Windows 用户。
- 不要连续双击主程序，不要手工结束 Supervisor、SessionAgent 或 SafetyAgent。
- 不要直接修改 `C:\Program Files\MTTFTest\Current` 中的程序或配置。
- 出现恢复窗口时等待自动处理；人工静音只关闭蜂鸣器，故障灯和锁存仍保持。
- 确认卡钳、液压或电路硬件故障后不会自动重新上电，必须维修并重新复核。

## 候选与正式放行边界

本包运行的是完整服务化无人值守架构，但状态仍是现场候选：

```text
FIELD_CANDIDATE_PENDING_168H
```

必须通过真实硬件故障注入以及 24、72、168 小时长稳，才允许晋升 LastKnownGood 和签署正式无人值守放行。在此之前，不得把候选状态改写为正式通过。

## 故障处理

安装失败：保存命令窗口内容，不要修改 manifest 或绕过哈希门禁。

服务异常：先运行 `一键修复.cmd`。

需要停止使用：先在主程序安全停止，再运行 `一键卸载.cmd`。

查看状态：运行 `检查运行状态.cmd`。
