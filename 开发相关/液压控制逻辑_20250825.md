# 控制逻辑

## 目标

- 同一气缸为 2 个电源组（各 3 个卡钳，共 1..6）建压；**液压释放**必须发生在**本次启用的所有卡钳里最后一个到达“电压释放点”**之后。
- 组内“错峰”：序号 1 → 2 → 3 依次执行；两组**同序号**（1&4、2&5、3&6）**基本同时**。

## 关键规则

1. **启用集合**：本次循环的启用卡钳集合 `A ⊆ {1..6}` 运行，未启用的忽略。
2. **时间轴**：每个启用的卡钳 `i` 有一个“电压释放点”时间 `t_rel[i]`（相对循环起点）。
   - 若 `i` 与其配对（1↔4、2↔5、3↔6）都启用，则两者时间相同（同序号同时）。
   - 组内错峰由固定偏移（例如 Δ）形成：序号1偏移0，序号2偏移Δ，序号3偏移2Δ。
3. **保持-聚合释放**：气缸在循环开始时**建压并保持**；当且仅当**A 中所有卡钳**都到达其各自“电压释放点”后，**一次性释压**。
4. **容错**：任一启用卡钳异常/超时/取消 ⇒ 立即**安全释压**并判失败。
5. **子集示例**：若启用 `{1,3,5}`，则 `t_rel[1]=t_rel[5] < t_rel[3]`，最终以 `3` 的释放点为气缸释压时刻。

## 状态机（一次循环）

```
Idle → Build(建压) → Hold(保持) → WaitAll(等所有启用卡钳到其电压释放点) → Release(释压) → Done/Fail
```

- `Build/Hold` 由液压控制器（你的 `HydraulicController.HoldUntilRelease`）完成；
- `WaitAll` 由**释放协调器**聚合各卡钳的“释放到达事件”。
