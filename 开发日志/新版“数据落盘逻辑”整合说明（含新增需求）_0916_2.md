# 新版“数据落盘逻辑”整合说明（含新增需求）

> 目标：以**简化记录格式**（仅电流/压力 + 必要元信息）+ **循环号与真实动作绑定**为核心，补充**空闲/自由记录（cycle=0）**与**停止即落盘（最新 N 圈）**两项行为，形成统一、可落地的落盘架构。

------

## 1. 记录格式（精简版）

**单条记录字段**（32 B/条）

- `TimestampBinary` (Int64, 8B)：UTC 时间戳（`DateTime.ToBinary()`）。
- `CycleNumber` (Int32, 4B)：循环号；**正式试验 > 0**；**自由记录为 0**。
- `SampleIndex` (Int32, 4B)：该循环内样本序号，从 0 递增。
- `EpbCurrent` (Double, 8B)：电流（工程值）。
- `GroupPressure` (Double, 8B)：组压力（EPB1–6→P1，EPB7–12→P2）。

> ⚠️ 所有**预留字段移除**；仅保留上述 5 项（合计 32 B）。

------

## 2. 运行模式与循环号来源

### 2.1 正式试验模式（Managed Cycle Mode）

- 循环号来源：`EpbManager` 每通道的定时器回调参数 `i`（第 i 圈）。
- 进入/退出：
  - `BeginCycle(epbId, i)`：开始圈 `i`。
  - `CompleteCycle(epbId, i, finalCount, endUtc)`：圈 `i` 结束。
- 写入规则：期间采到的样本一律打上 `CycleNumber = i`。

### 2.2 空闲/自由记录模式（Free-Run Mode）

- 适用场景：未开启 `EpbManager` 循环，也允许写入数据。
- **循环号固定为 0**（与正式试验明确区分）。
- 进入/退出：
  - `StartFreeRun(epbId)` / `StopFreeRun(epbId)`（**显式方法开启/关闭**）。
- 写入规则：当 Free-Run 对应通道**启用**时，采样批次写入 `CycleNumber = 0`。
- 用途：在线监控、设备空闲自检、突发留痕等。

> ✅ 两模式可**按通道独立存在**。同一通道上，**正式循环优先级更高**（一旦 `BeginCycle`，即刻切换到“正式试验模式”，Free-Run 对该通道暂时不生效；`CompleteCycle` 后恢复到 Free-Run 状态（若仍开启））。

------

## 3. 存储介质与索引（保持之前方案的一致性）

- **介质**：每个 EPB 一个固定大小 `.dat` 内存映射文件（记录级循环覆盖，滑动窗口）。
- **索引**（SQLite）：仅存**循环级元数据**（`epb_id / cycle_number / start_record_index / sample_count / start/end_time / status`）。
  - **不为 Free-Run（cycle=0）建圈级索引**（减少索引量）；Free-Run 导出/回放通过“时间窗/样本数”直接读环缓。
  - 正式试验的每圈都有索引项，用于**精确“最新 N 圈”选择、导出、保留**。

------

## 4. “最新 N 圈”保留与停止时落盘

### 4.1 全局保留策略（常规）

- **只保留每通道最新 N 圈**（默认 N=10，可配置）。
- 策略动作：
  - `delete`：仅删索引（.dat 自然会覆盖最旧数据）。
  - `archive`：导出 CSV 后删索引。
- 触发时机：
  - 定时/手动触发 `ApplyRetentionPolicy()`；
  - 或在“试验/圈完成”后做轻量触发（可选）。

### 4.2 **新增**：停止即落盘（强制保留最新 N 圈）

> “不管何时，只要**停止卡钳**，就应当把**该卡钳最新 N 圈**数据落盘；**N 默认 10**，**时机可由用户指定**。”

- API 思路：
  - `SetStopRetentionOption(epbId, keepLatestN = 10, action = "archive"|"delete", trigger = StopTrigger)`
  - `StopTrigger` 支持：
    - `Immediate`：立刻停止并执行保留（若正处于圈内，当前圈按**已采到的样本**作为最终计数）。
    - `EndOfCurrentCycle`：等当前圈结尾再停止并保留。
    - `AfterNMoreCycles(k)`：k 圈后停止并保留。
- 执行动作：
  - 停止事件发生 → `PersistLatestCyclesNow(epbId, keepLatestN, action)`
    - `archive`：导出最新 N 圈（>0 的正式圈）到 `Archive/EPB#/*.csv`；
    - 然后删索引中早于“最新 N 圈”的条目（释放索引压力）。
- **注意**：
  - 只针对**正式圈（CycleNumber>0）**计算“最新 N 圈”。
  - Free-Run（cycle=0）不参与“最新 N 圈”；如需 Free-Run 数据，提供**单独导出 API**（见 §5.3）。

### 4.3 **新增**：未开循环也能写（Free-Run ON）

> “如果没有开启 EpbManager 的循环，也允许存储数据，不过循环号一直是 0；这个存储需要**有个方法来开启**。”

- 用户/上层可显式调用 `StartFreeRun(epbId)`，采样批次被写入为 cycle=0。
- 当某卡钳在正式试验中**中途停止**时（比如做“每圈后停止”的调试），**仍然**会在停止动作上按§4.2 **强制保留**其“最新 N 圈”正式数据。
- Free-Run 数据默认仅在环缓中保留（不断覆盖）；如需“抓取空闲窗口”，见 §5.3。

------

## 5. 对外接口（草案）

以 `EpbDiskWriter`（内存映射 + 索引）为中心，提供以下接口：

### 5.1 试验圈相关

- `BeginCycle(int epbId, int cycleNumber, DateTime startUtc)`
- `WriteSample(int epbId, in SampleRecord rec)`（内部自动打上**当前模式**下的 `CycleNumber`；正式圈期间优先）
- `CompleteCycle(int epbId, int cycleNumber, int finalSampleCount, DateTime endUtc)`

### 5.2 空闲/自由记录

- `StartFreeRun(int epbId)` / `StopFreeRun(int epbId)`
- `IsFreeRunOn(int epbId) : bool`

### 5.3 导出/落盘动作

- `ApplyRetentionPolicy()`：执行“只保留最新 N 圈”（全局/每通道）。
- `PersistLatestCyclesNow(int epbId, int keepLatestN = 10, string action = "archive")`：**立即**对某通道执行“最新 N 圈保留”。
- `ExportCycleToCsv(int epbId, CycleInfo cycle, string csvPath)`
- **（Free-Run 导出）** `ExportFreeRunWindow(int epbId, TimeSpan window, string csvPath)` 或 `ExportFreeRunBySamples(int epbId, int sampleCount, string csvPath)`：从环缓尾部回溯导出最近一段 Free-Run 数据（`cycle=0`）。

### 5.4 停止行为配置（新增）

- `SetStopRetentionOption(int epbId, int keepLatestN = 10, string action = "archive", StopTrigger trigger = StopTrigger.EndOfCurrentCycle)`
- 由上层在**停止卡钳**动作前设置；`StopChannel(epbId)` 时按选项执行对应的**强制保留**流程。

------

## 6. UI 与集成点

### 6.1 `FrmEpbMainMonitor`

- 替换旧落盘定时器/队列调用为 `EpbDiskWriter`；
- 新增控件：
  - 每通道 **Free-Run 开关**（“◉ 空闲记录”）；
  - 每通道 **停止落盘选项**（保留圈数 N / 动作 `archive|delete` / 触发 `Immediate|EndOfCurrent|AfterK`）；
  - “Stop & Persist” 快捷按钮（立即按当前选项执行 §4.2）。

### 6.2 `EpbManager`

- 在每通道定时器回调：
  - 圈开始：`BeginCycle(epb, i, UtcNow)`
  - 圈采样期间：采集批次由采集层驱动，落盘器自动识别当前模式；
  - 圈结束：`CompleteCycle(epb, i, cnt, UtcNow)`
- 在“停止卡钳”逻辑里：读取并应用 `StopRetentionOption` → 调用 `PersistLatestCyclesNow(epb, keepN, action)`。

### 6.3 采集层（`TwoDeviceAiAcquirer` / 你的 “工程值批次” 事件）

- 批次回调中，针对每个通道：
  - 取电流；
  - 基于 `epbId<=6 ? P1 : P2` 取对应压力；
  - 构造 `SampleRecord`（`TimestampUtc`, `EpbCurrent`, `GroupPressure`，`SampleIndex` 按圈内累加）→ `WriteSample(epbId, rec)`；
  - `CycleNumber` 由写盘器根据**通道当前模式**（正式/Free-Run）填写。

------

## 7. 边界与优先级

- 同一通道：**正式圈优先**；一旦 `BeginCycle`，该通道写入强制 `CycleNumber=i`，直至 `CompleteCycle`。
- Free-Run 与正式圈之间切换不丢样：切换点由上层在批次边界触发（或在写入端原子切换状态）。
- “停止即落盘”仅对**正式圈**生效（>0）。Free-Run 数据默认不参与“最新 N 圈”统计；如需抓取，请调用 Free-Run 导出 API。

------

## 8. 接口默认值与建议

- `keepLatestN` 默认 **10**；
- 停止触发默认 `EndOfCurrentCycle`（更“整圈”）；
- 保留动作默认 `archive`（导出 CSV 再清索引）；
- Free-Run 默认 **关闭**（避免无意识写盘），需显式开启。

------

## 9. 验收清单（Checklist）

-  记录格式仅 5 字段（32B/条），无预留字段。
-  正式圈的循环号与 `EpbManager` 回调 `i` 一致。
-  Free-Run 支持（cycle=0），可显式开启/关闭。
-  停止卡钳时，自动/按用户设定**强制保留最新 N 圈**（默认 10，支持 `Immediate/EndOfCurrent/AfterK`）。
-  “最新 N 圈”仅统计 **CycleNumber>0** 的圈。
-  导出能力：圈级 CSV；Free-Run 窗口导出。
-  与现有窗体/采集层/管理器的对接点落地。
