# 目标（复述）

1. **正向阶段**：上电→忽略涌流→**直接**进入“夹紧阈值判定”（不再单独判空行程）。
   - 好处：避免“空行程很短”且“空行程内超限”的现场导致过流；简化参数（不再需要空行程电流与带宽）。
   - 行为：达到阈值/平台（或预测将触达）→立刻断电、标记释放。
2. **反向阶段**：上电→忽略涌流→**测量一个刚性的反向峰值衰减时长**→再执行**固定时长**的“反向空行程”，期间只需满足“电流低于某个衰减限值”（如 3A），不再用“空行程值+带宽”去判断。
   - 反向“空行程时长”固定（比如 1000ms），**非判据**，只是策略时间。
   - 用一个**反向电流衰减限值**（如 3A）来判断“处于空行程区间”，无需均值/带宽窗口。

# 拆解为可实施方案

## 一、参数（建议命名 & 默认值）

- 通用
  - `PeakIgnoreMs`（上电涌流忽略）：**维持**现有（例如 10~30ms）。
  - `ClampThrA`（正向夹紧电流阈值）：**沿用**现有 `_posThrA`。
  - `PredictiveCutMs`（预测提前切断窗口）：**建议保留**（默认 5ms），与现有 `WaitCurrentAboveAsync` 一致。
  - `HoldMs`（保持）：**保留**（⑤段）。
- **反向限定**
  - `RevDecayRigidMaxMs`（反向峰值衰减最大等待）：例如 **80~150ms**；用于“刚性衰减时长”的**上限**测量窗口。
  - `RevEmptyFixedMs`（反向空行程固定时间）：例如 **1000ms**（你建议值）。
  - `RevDecayLimitA`（反向衰减限值）：例如 **3A**；判定“进入反向空行程电流区间”的简化阈值（不再用带宽）。

> 注：`RevDecayRigidMaxMs` 的作用是：在忽略涌流后，给反向电流一个“最多 X ms 的衰减窗口”，在这段时间里我们等待电流**降到** `RevDecayLimitA` 以下；用这个**达到时刻**（或超时）来**记录“反向峰值衰减时长”**。然后，无论是否在窗口内真正达到该限值，我们都会进入固定的 `RevEmptyFixedMs` 阶段（⑦），但会把“是否达到/是否超时”写入日志与 LearnSample，便于后续分析。

## 二、正向阶段（②~④ 合并为“直接夹紧判据”）

1. **上电正向** → `await Task.Delay(PeakIgnoreMs)`（忽略涌流）。
2. **立即进入阈值判定**：沿用 `WaitCurrentAboveAsync(thr = ClampThrA, ...)`。
   - 保留你原先的**预测提前断电**与**平台检测**逻辑（降低过流概率）。
   - 一旦返回 `true` → **立即断电** + `HydraulicMarkReleaseAsync`。
3. **不再**回溯“空带上边界上穿/阈值上穿”，也就**不再输出** `TFwdEmptyMs`、`TClampRampMs` 这两个分段量（可整合为一个“正向阶段耗时”或把这两个字段置零/弃用，详见“数据返回”）。

## 三、保持阶段（⑤）

- 若 `HoldMs > 0` → `await Task.Delay(HoldMs)`。

## 四、反向阶段（⑥~⑦）

1. **上电反向** → `await Task.Delay(PeakIgnoreMs)`（忽略涌流）。
2. **测量刚性的反向峰值衰减时长**（⑥）：
   - 在最长 `RevDecayRigidMaxMs` 的窗口内，**轮询当前电流**，一旦 `current <= RevDecayLimitA`，即刻记录**衰减达标时刻**（`TRevPeakDecayMs`）；
   - 若窗口结束仍未达标，则记 `TRevPeakDecayMs = RevDecayRigidMaxMs`，并在日志中告警“衰减未达标”。
3. **固定反向空行程**（⑦）：
   - 无条件执行 `await Task.Delay(RevEmptyFixedMs)`；
   - 在这段固定时间**不再做窗口均值/带宽判定**，仅可选地**监视**是否长期高于 `RevDecayLimitA` 并记告警（可选）。
4. **反向断电**。

## 五、返回数据（LearnSample）与兼容

- 你现在的 `LearnSample` 字段包含：`TFwdPeakDecayMs`、`TFwdEmptyMs`、`TClampRampMs`、`TRevPeakDecayMs`、`TRevEmptyMs`、`IEmptyFwdA`、`IEmptyRevA`。
- 在新方案里：
  - **正向**：
    - 仍可保留 `TFwdPeakDecayMs`（指忽略涌流后的“涌流衰减时长”，如果你希望记录）。
    - `TFwdEmptyMs`、`TClampRampMs`：**建议置 0** 或 **标记为废弃**（保留字段以兼容上层聚合，再由聚合端忽略这两列）。
    - `IEmptyFwdA`：**不再评估**，建议置 `0`。
  - **反向**：
    - `TRevPeakDecayMs`：按上面“刚性衰减测量”的结果填充（可能为 `< RevDecayRigidMaxMs` 或等于上限）。
    - `TRevEmptyMs`：直接填固定值 `RevEmptyFixedMs`（如 1000ms）。
    - `IEmptyRevA`：**不再评估**，建议置 `0`。
- **可选增强**：新增一个 `ForwardPhaseMs`（从正向忽略涌流结束到阈值触达/预测触达的总耗时）作为“正向阶段合并统计”，以替代 `TFwdEmptyMs + TClampRampMs` 的意义。也可以把它写入 `TFwdPeakDecayMs` 或新增字段，取决于你是否仍要记录“忽略涌流后的真实衰减时间”。

> 为保持上层最小改动：我建议**暂时不改 LearnSample 结构**，直接把无意义字段**置 0**，并**新增一个扩展字段**（可选）或在日志中明确记录“ForwardCombinedMs”。

## 六、风险与防护

- **空行程中即超阈值**：你的方案通过**直接阈值/预测**剪切，**显著降低过流风险**。
- **误检触发**（电磁噪声/瞬态毛刺）：建议保留 `WaitCurrentAboveAsync` 中的**平台检测**与**斜率下限**（`minSlopeAperMs`），并考虑在**接近阈值**时加一段**微短的确认窗**（例如 2~3 个样本连续满足）以减小瞬态导致的误判。
- **反向衰减未达标**：在 `RevDecayRigidMaxMs` 超时仍 > `RevDecayLimitA` 时，**继续进入固定空行程**，但**记录告警**（统计/报表可见），方便后续硬件/润滑状态排查。
- **参数可运维**：把 `RevDecayRigidMaxMs`、`RevEmptyFixedMs`、`RevDecayLimitA` 放到配置文件中，按通道或全局可配，便于现场微调。

## 七、具体流程时序（精简版）

- **②正向**：`FWD ON` → `Delay(PeakIgnoreMs)` → `WaitCurrentAboveAsync(ClampThrA, predictiveCut=on)` → `OFF` → `HydraulicMarkRelease(...)`
- **⑤保持**：`Delay(HoldMs)`（可为 0）
- **⑥反向衰减**：`REV ON` → `Delay(PeakIgnoreMs)` → 在 `RevDecayRigidMaxMs` 内等待 `I <= RevDecayLimitA`（记录 `TRevPeakDecayMs`，超时=上限）
- **⑦反向固定空行程**：`Delay(RevEmptyFixedMs)`
- `OFF` → 返回 `LearnSample`（正向空行程/带宽相关字段=0）
