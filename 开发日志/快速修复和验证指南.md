## 集成到现有系统

一旦基本功能验证通过，您可以：

### 1. 在数据采集中集成
```csharp
// 在您的数据采集类中添加
private EpbMemoryMappedStorage _memoryStorage;

// 初始化
_memoryStorage = new EpbMemoryMappedStorage("DataStore", 10, 300000);

// 在AI数据回调中写入
private void OnAIDataReceived(double[] aiValues)
{
    for (int epbId = 1; epbId <= 12; epbId++)
    {
        double current = GetEpbCurrent(epbId, aiValues);
        double pressure = GetGroupPressure(epbId);

        _memoryStorage.WriteSample(epbId, current, pressure);
    }
}
```

### 2. 在界面中展示数据
```csharp
// 获取最新数据用于实时显示
var latestSamples = _memoryStorage.GetLatestSamples(epbId, 100);

// 获取历史循环数据
var cycleData = _memoryStorage.GetCycleData(epbId, cycleNumber);

// 更新图表
UpdateChart(latestSamples);
```

### 3. 配置文件设置
在Config目录创建`DataRetentionPolicy.xml`：
```xml
<?xml version="1.0" encoding="UTF-8"?>
<DataRetentionPolicy>
    <StorageMode>MemoryMapped</StorageMode>
    <RetainLatestCycles>10</RetainLatestCycles>
    <FileSize>384</FileSize>
    <SampleRecordSize>128</SampleRecordSize>
    <DataStorePath>DataStore</DataStorePath>
    <SamplesPerCycle>300000</SamplesPerCycle>
    <EnableAutoFlush>true</EnableAutoFlush>
    <FlushIntervalSeconds>30</FlushIntervalSeconds>
</DataRetentionPolicy>
```

## 性能参数调整

根据您的具体需求，可以调整这些关键参数：

- **RetainLatestCycles**: 保留循环数（默认10个）
- **SamplesPerCycle**: 每循环采样数（默认30万）
- **FileSize**: 单个EPB文件大小MB（默认384MB）
- **DataStorePath**: 数据存储路径

## 故障排除

**内存不足**：
- 减少RetainLatestCycles或SamplesPerCycle
- 确保有足够的磁盘空间（约5GB）

**权限问题**：
- 以管理员身份运行
- 更改DataStorePath到有写权限的目录

**数据查询慢**：
- 检查SQLite索引是否正确创建
- 限制查询的时间范围
