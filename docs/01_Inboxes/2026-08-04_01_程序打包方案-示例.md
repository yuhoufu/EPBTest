# 为EPB常温疲劳试验台软件创建 Windows 安装包

请为当前解决方案创建一个基于 Inno Setup 的安装包工程，并增加完整的一键构建脚本。

## 技术环境

- Windows 10/11
- Visual Studio 2022
- C#
- .NET Framework 4.8
- C# 9
- WinForms 或 WPF 桌面程序
- 安装包工具：Inno Setup 6
- 构建脚本：PowerShell 7，同时尽量兼容 Windows PowerShell 5.1

## 目录结构

请创建：

```text
installer/
├─ PressureVolume.iss
├─ Includes/
└─ Assets/

scripts/
├─ Build.ps1
├─ Publish.ps1
└─ BuildInstaller.ps1

publish/
artifacts/
```

## 安装包要求

1. 默认安装目录：

```text
C:\Program Files\Horizon\PressureVolume\
```

1. 创建开始菜单快捷方式。
2. 提供可选的桌面快捷方式。
3. 在 Windows“已安装的应用”中显示：

- 软件名称
- 软件版本
- 发布者
- 软件图标
- 卸载入口

1. 安装前检测程序是否正在运行。
2. 如果程序正在运行，应提示用户关闭；必要时允许安装器自动关闭。
3. 支持覆盖升级旧版本。
4. 升级时不得删除用户配置、标定数据、许可证、数据库、日志和历史测试数据。
5. 卸载主程序时，默认保留用户数据。
6. 卸载时可以询问用户是否同时删除用户数据。
7. 安装结束后提供“启动程序”选项。
8. 支持静默安装和静默卸载。
9. 安装包输出名称格式：

```text
PressureVolume_Setup_{Version}_x64.exe
```

## 目录规划

程序文件安装到：

```text
{autopf}\Horizon\PressureVolume
```

公共数据目录：

```text
{commonappdata}\Horizon\PressureVolume
```

当前用户配置目录：

```text
{localappdata}\Horizon\PressureVolume
```

首次安装时创建以下目录：

```text
Config
Calibration
Templates
Logs
Database
License
```

## 前置环境

检测 .NET Framework 4.8 是否已经安装。

如果缺失：

- 给出明确提示；
- 支持调用离线安装程序；
- 前置环境安装失败时不得继续安装主程序。

NI-DAQmx Runtime 和其他大型硬件运行环境不要直接嵌入主程序安装包，预留外部检测及调用接口。

## 构建脚本要求

创建统一入口：

```powershell
.\scripts\BuildInstaller.ps1 -Configuration Release -Version 1.0.0
```

脚本执行：

1. 检查 MSBuild 是否可用。
2. 检查 Inno Setup 编译器 `ISCC.exe` 是否可用。
3. 清理旧的 `publish` 和 `artifacts`。
4. 编译解决方案。
5. 收集主程序、DLL、配置、资源和模板。
6. 排除 `.pdb`、`.xml`、`.vshost.*` 等非发布文件，但允许通过参数保留 PDB。
7. 将版本号传递给 Inno Setup。
8. 编译安装包。
9. 生成绿色版 ZIP。
10. 生成 SHA256 校验文件。
11. 任一环节失败时立即退出，并返回非零退出代码。
12. 输出清晰的中文构建日志。

## 代码质量要求

- 不写死当前开发电脑的绝对路径。
- 路径统一基于仓库根目录计算。
- 所有脚本支持路径中包含空格和中文。
- 对缺失文件给出明确错误信息。
- 不静默忽略构建错误。
- 对关键逻辑添加中文注释。
- 不修改现有业务代码，除非为适配数据目录和版本读取确有必要。
- 所有新增文件适合提交到 Git。
- 在 `README-Installer.md` 中说明安装包的构建、测试、升级和发布流程。
