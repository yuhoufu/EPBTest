### 行选择与校正点更新

| 需求 | 落地规则 |
| --- | --- |
| 只高亮选中行 | 表格保持 `FullRowSelect`；选中行为浅蓝色 `#CCE2FF`。表头普通背景和表头选中背景统一为现有主题蓝 `#50A0FF`，选择单元格时不再额外高亮当前列表头。 |
| 选择历史点后联动命令压力 | 停止输出状态下选择任意历史行，命令压力输入框自动同步该行的命令压力，并在底部状态栏提示行号和压力值；正在输出时禁止切换校正目标并提示先停止输出。 |
| 相同命令压力更新旧点 | “记录当前点”按 `0.01 bar` 容差查找最接近的已有命令压力。命中时原位更新实测压力和 AO 电压，不追加重复点；未命中时才新增记录。 |
| 标识本轮改动点 | 新增点或被更新的历史点使用淡蓝底 `#E6F2FF`、蓝色文字和工具提示进行标识；排序后仍保持该行选中，方便继续核对。 |
| 删除和清空防误操作 | 删除选中点前显示命令压力、实测压力和 AO 电压；清空全部点前再次确认。删除/清空仅修改页面数据，仍需点击“保存校正”才写入配置。 |

### 部分更新历史点的拟合风险提示

保存前区分“本轮新增/更新点”和“载入后未更新的历史点”。两类数据同时参与拟合时，页面给出确认提示，包含新点数、旧点数、混合拟合公式及 `R²`：

- 本轮只有 1 个更新点时，明确提示无法单独评估新趋势，建议继续更新其他旧点或删除不再使用的旧点。
- 本轮至少有 2 个更新点时，额外拟合本轮趋势，并计算未更新旧点相对该趋势的最大偏差。
- 风险判断阈值为：混合拟合 `R² < 0.995`，或旧点最大偏差超过 `max(2 bar, 全部点压力跨度 × 2%)`。
- 风险确认框默认选择“不保存”，由操作员确认是否继续，避免新旧点无提示混用。

### 开发机与现场机自适应

- 设置窗口打开时根据当前屏幕工作区和实际 DPI 计算尺寸并居中，不再由窗体自身使用固定开发机尺寸覆盖主窗口计算结果。
- 基准尺寸为 `1415×780 @ 96 DPI`；在 `192 DPI` 下等比目标为 `2830×1560`，超出时自动限制在当前屏幕工作区并保留安全边距。
- 校正页面的动态字体由 Windows DPI 管理；绝对行高、列宽、间距和按钮尺寸按实际 DPI 显式等比缩放，解决高 DPI 下“字体放大但布局尺寸未放大”导致的省略和裁切。
- 颜色继续沿用现有 Sunny.UI 设置页的主题蓝 `RGB(80, 160, 255)`，未引入与既有界面冲突的新主色。

### 主菜单清理

- 删除无业务用途的“窗口管理 (W)”菜单，以及“水平排列 / 垂直排列 / 层叠排列”子菜单和对应事件处理器。
- 该调整只移除 MDI 窗口排列入口，不影响试验菜单、设置菜单、运行身份或试验执行逻辑。
