# 3.0.0.0 一键部署包使用说明

完整解压7z后再操作，不要在压缩软件中直接运行EXE。根目录Package是主程序及监督组件，Guard是独立观察组件；不要单独复制或混装。先阅读随交付记录的SHA256与验收状态。

| 双击入口 | 用途 |
|---|---|
| 一键安装正式版.cmd | 校验完整包，安装Main，再安装ObserveOnly Guard |
| 启动试验.cmd | 向Supervisor申请启动主窗口，不直接运行EXE |
| 检查运行状态.cmd | 显示安装版本、服务、任务和进程；不代表业务健康 |
| 一键修复.cmd | 用同包修复Main和Guard；需要先正常停止并退出 |
| 恢复后台服务.cmd | 按现有维护协议恢复监督组件 |
| 一键故障采证.cmd | 使用现有采证器保存证据；不会自动清理现场日志 |
| 一键停止全部相关进程.cmd | 走现有安全停止、撤权与清场流程；安全条件不满足时明确阻塞 |
| 一键卸载.cmd | 要求主程序退出，先卸载Guard，再卸载Main；保留数据和停止记录 |

各入口自动申请管理员权限。请使用现场原操作员账户并确认UAC，不用另一个管理员账户替代，以免改变交互会话身份。安装主程序需要正常停机和保存；不会自动确认物理断能，不绕过现有安全门禁。首次Guard台架标识使用计算机名，已有合法注册沿用原标识，屏幕会显示实际值；已有授权路径冲突时由安装器拒绝。

Guard执行任务始终禁用，默认只观察。安装成功不等于现场硬件或自动恢复验收通过。当前没有CAN硬件，不检测CAN。I0050修复仍留在第二步。

如果某一步失败，窗口显示步骤和错误，ProgramData\MTTFTest\DeploymentLogs保存操作日志。Main安装成功而Guard失败属于部分完成，不能当作整体成功；先查日志再运行修复。不要手改包内文件，否则完整性检查将拒绝。

回退前正常停止保存、确认无在途接管并备份当前数据。使用已核验旧程序及配置备份恢复组件，恢复原服务/任务定义；保留新版产生的数据和日志并核对新增完成圈，禁止覆盖回旧数据或回放旧许可。现场回退需按已批准维护方案执行，不能靠直接双击旧EXE绕过Supervisor。

wj-epb正式试验期间禁止安装、修复、停止、卸载或重启服务。需要先确认维护窗口，完成最新一致备份、圈数对账与现场安全确认。
