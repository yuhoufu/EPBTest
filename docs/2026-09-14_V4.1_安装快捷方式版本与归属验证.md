# V4.1 安装快捷方式版本与归属验证

## 修改

完整包文件安装器在 Provision 完成后调用管理器 `Shortcut` 入口。快捷方式版本取自注册主程序的实际 FileVersion；此前安装器已核对主程序、SafetyAgent、FallbackGuard 与包清单版本一致。快捷方式名称为 `MT EPB V<实际版本> [<安装ID>].lnk`，放到公共桌面，指向注册 EXE，工作目录为其所在目录，不携带自动开始参数。

安装 ID 区分不同安装，不覆盖同名但归属不同的文件。重复创建先核对目标路径、工作目录、空参数、安装描述；一致则保留，不一致则报错并保留文件。创建使用同目录临时文件及不覆盖的移动操作，失败清理本次临时文件，COM 对象在 finally 释放。

卸载管理器只删除版本、安装 ID 及上述属性均匹配的入口，不按名称模糊删除其他快捷方式，也不批量删除旧版本入口。缺失入口视为已移除；冲突入口保留并明确报错。此项尚不等同于完整二进制卸载或跨版本升级/回滚完成。

## 限制与后续

上述验证证明快捷方式函数在本机和 jxcq 的 Windows Shell 中可执行，不代表最终安装包在公共桌面的安装/卸载及权限流程全部通过。完整安装、二进制修复、升级、回滚、统一版本和发布包仍须完成。当前程序仍为 4.0.0.3，本轮未创建 4.1.0.0 最终包或标签，未操作 WJ-EPB。
