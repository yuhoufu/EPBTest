## 维护窗口内的放行条件

1. 正常停止并保存，逐通道对账最后完成圈、在途作废圈、检查点和数据库提交，确认设备安全状态。
2. 完成程序、配置、服务/任务定义及项目数据的一致性备份，核对摘要和可读性，明确回退后新增数据的保留方式。
3. 现场传输后核对上述ZIP摘要，解压，使用Windows PowerShell 5.1执行`Verify-Bundle.ps1`。
4. 使用`Main/Deployment/Install-MTTFTest-Unattended.ps1`升级实际安装根目录；安装器安全门禁不通过时停止处理，不预填断能确认绕过。
5. 安装配套Guard，绑定现场确认的台架标识和实际Main路径，指定ObserveOnly；确认执行任务禁用。
6. 完成NI、电源、液压的实际验收，核对项目和剩余目标后，由现场确认续测；以采样、控制和持久提交推进判定业务正常。

I0050液压恢复状态发布一致性修复仍按用户要求留到第二步。本包没有被证明可消除该根因。当前项目无CAN硬件，不检测CAN，不把CAN列为准入项。

## 当前结论

软件侧证据支持进入维护窗口内的受控升级观察与验收；尚未证明正式带载运行和自动恢复验收通过。原目标继续保留，现场操作依赖用户确认窗口及上述实际验收条件。
