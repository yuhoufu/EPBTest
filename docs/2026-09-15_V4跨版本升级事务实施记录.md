# V4 跨版本升级事务实施记录

## 当前实现范围

文件安装器增加 `Get-IndependentUpgradePlan`，输入必须是分别经安装包路径/摘要验证得到的旧、新文件计划及原安装记录。函数只生成计划，尚未开放 Upgrade 执行入口，不修改任何文件或试验状态。

旧包必须与原安装记录同构建；新旧计划必须指向同一规范安装目录，新版本必须严格高于旧版本。相同版本应走 Repair；低版本回滚必须使用专门的回滚流程，不能冒充 Upgrade。

计划分为：新程序组件、旧包有而新包没有的待退出组件、应保留的原配置及非组件文件。沿用程序组件扩展名范围，配置目录全部排除；不把新包默认配置直接覆盖现场配置。旧组件列表保留其原摘要，供后续事务核验归属和恢复。

## 已验证

`Test-UpgradePlan.ps1` 在 Windows PowerShell 5.1 x86 下 6/6、exit 0：

- 正常升级正确识别替换、新增、退出组件；旧配置及数据库进入保留集合。
- 同版、降级、非法版本拒绝。
- 其他安装目录拒绝。
- 原安装记录与旧包摘要不一致时拒绝。

日志位于主仓库 `Codex/v41-upgrade-plan-test.log`。此为计划函数测试，没有执行升级；未访问 jxcq 或 WJ-EPB。
