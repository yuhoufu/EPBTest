# V4.1 整批暂停与继续的持久授权

承接 `d92ed0e`。本轮仅本地代码和回归，没有操作现场或 jxcq。

## 实现

监控窗口的暂停入口先异步持久保存 `ManualPaused=true`，成功后才请求控制器等待当前圈安全结束。独立服务从这次写入起不再把该批次当作可自动续测目标；不能等 UI 或主控制器最终暂停回执才撤销恢复权限。

明确点击继续时，先按精确进程身份和 RunId/RunEpoch 恢复该批次的运行意图，再执行原有恢复预检。新观察窗口只由这个明确继续操作开启；重复暂停/继续、服务重启不会不断延长期限。这里的 `RunStartedUtcTicks` 在继续时表示本次运行观察窗口开始，RunId/RunEpoch 和根批次不变。

新增 `SetControllerManualPause` 在单个持久事务中校验 PID、启动时间、路径、Windows 会话、会话令牌与当前批次。外来进程、旧批次、活动恢复/安全清理中的继续操作均拒绝。整批人工停止后不能借“继续”清除停止意图，必须走明确的新开始。

对于已经 Verified 的恢复进程，暂停/继续更新当前意图及事务修订，保留精确进程绑定。原凭证已消费，不能再次启动进程；没有把这张历史凭证重新变成可消费许可。尚未完成的启动凭证仍随暂停撤销，由既有清理链处理。

持久写入失败时操作不会报告暂停或继续完成；原有硬件预检、保护阈值和圈计数没有被修改。
