# 一键自动恢复安装与修复

完整解压后，双击最外层“一键安装正式版.cmd”或“一键修复.cmd”，接受 Windows 管理员权限提示即可。不需要传入现场验收报告或其他参数。

首次安装默认 RecoverExited（主程序退出后的自动恢复）。修复保留已经安装的 RecoverExited 或 RecoverStalled 模式。Base 内部同名入口也转到同一安装流程，不会切回 ObserveOnly。

安装仍检查包文件哈希、主程序和 Guard 版本及共享组件一致性、既有台架身份、运行中接管状态和主程序安全停止条件。安装成功后，试验仍由操作人员显式启动。

按使用方要求，现场验收报告不再作为安装和修复的前置条件。本包没有生成或宣称通过任何现场硬件验收报告，也没有改变恢复过程中的物理安全与执行许可检查。

主程序与 Guard 二进制来自已验证的 0f28efe9d33d 提交；新版部署脚本提交另记于 deploymentToolsCommit。旧报告制安装包保留不变，日常使用新版 AUTO_RECOVERY_ONECLICK 目录。
