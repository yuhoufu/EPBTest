# V4.1 独立执行器组合安装入口

## 本次修改

`Tools/Manage-IndependentRecovery.ps1` 新增 `Provision`，顺序调用现有 Prepare、Install、Enable。准备失败不会安装；安装失败由 Install 原有逻辑清理本调用创建的对象；只有 Install 成功后，Enable 失败才调用 Uninstall 撤回本次服务和任务。持久状态、绑定与诊断保留，不删除项目或修改计数。清理也失败时聚合保留两个异常，不能报告安装完成。

此入口只接受已落到受保护路径的组件，沿用注册、配置及 ACL 校验。已经存在的安装绑定或服务不猜测迁移；该入口不等于 Repair，也不会自动重试覆盖失败目录。

```powershell
.\Tools\Manage-IndependentRecovery.ps1 -Mode Provision `
  -RegistrationPath 'C:\Program Files (x86)\MTTFTest\IndependentState\registration.json' `
  -ExecutorPath 'C:\Program Files (x86)\MTTFTest\FallbackGuard\MTTFTest.FallbackGuard.exe' `
  -MainExecutablePath 'C:\Program Files (x86)\MTTFTest\Current\MTTFTest.exe' `
  -ProjectDirectory 'D:\隔离项目' -InteractiveUserSid '<实际交互用户账户 SID>'
```

示例路径须由完整安装器确定；不能直接复制示例用于现场。调用者须管理员权限，且旧控制程序已安全退出。成功只表示组件已启用；没有运行意图时服务等待用户明确开始，不自动建立试验授权。
