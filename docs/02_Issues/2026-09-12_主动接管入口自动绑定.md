# 主动接管入口自动绑定

StartSessionCoreAsync 创建新 SessionId；AttachRecoverySessionCoreAsync 使用恢复意图中的原 SessionId。因此会话身份可能随正常新会话变化，不能要求用户把旧 GUID 当作永久配置。

新增 Manage-ActiveFallback.ps1 和 Resolve-FallbackBinding.ps1：省略项目和会话时，从指定安装 Current 的唯一侧车读取命令行，校验新鲜快照、PID/启动时间、schema、Session 与 Run 一致。多个候选、未就绪或旧快照拒绝猜测。显式双参数仍供隔离软件测试使用。

自动绑定保存在当前账户 LocalAppData/MTTFTest/FallbackBindings，停用/查询/卸载可使用已保存的会话。新会话双击入口时，只在旧账本证明 Original/Idle 且无未决启动后卸载旧会话独立任务并绑定新会话。缺失或未决旧账本拒绝切换。

候选 BENCH_3 的 JXCQ启动主动接管.cmd 使用 Install 模式，一次点击自动建立后台任务。同一会话重复点击只启用/启动归属匹配的现有任务。不同路径的同名任务仍需先核对。

本变更消除每次手填参数，不实现永久后台发现新会话：正常新会话建立后仍需双击一次。原恢复链路沿用 SessionId 时无需重绑。禁用后不会因任务触发自动重新启用。

验证：Windows PowerShell 5.1 的自动识别专项涵盖唯一会话、空格路径、无侧车、多侧车、过期、启动时间/PID/Run/schema 错配、超限、原子缓存更新；二进制和恢复协议不变。
