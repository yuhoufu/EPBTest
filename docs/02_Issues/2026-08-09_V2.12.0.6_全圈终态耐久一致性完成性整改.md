# V2.12.0.6 全圈终态耐久一致性完成性整改

> **后续状态：** 本文保留圈终态一致性的阶段性证据。继续对照原始整改方案后，软预警默认整圈复制、容量反复递归扫描和四段运行身份截断已在 V2.12.0.7 修复；现场验证版本应使用 V2.12.0.7。详见 [V2.12.0.7 软预警 I/O 减负与运行身份完整性整改](./2026-08-09_V2.12.0.7_软预警IO减负与运行身份完整性整改.md)。

> 状态：代码、自动回归和脏候选完整性校验已完成；尚未获得生产部署批准。  
> 目标：消除所有可能在 Raw/耐久边界闭合前提交圈终态或清除圈身份的旁路。

## 1. 完成性审计结论

V2.12.0.5 已统一液压、电源、电气、普通软件预警和整台 DAQ 恢复的耐久收口。继续按“所有终态入口逐个反证”的方式审计后，发现以下旧旁路仍未接入统一协议：

1. Timer 运行看门狗异常直接废止当前圈；
2. 受影响液压组硬期限清场直接废止组内圈；
3. 活动圈样本上限处理直接废止圈；
4. 正式圈 Complete/Abort 等待持久化失败后，旧代码仍会降级提交 Abort 并清除圈号；
5. 报警圈封存失败时会立即降级 Abort，而不是保留圈并重试；
6. 学习/资格圈在 `SealAndExportCycle` 前没有统一等待 Raw/耐久前缀；
7. 写盘器的 Complete/Alarm/Abort 没有验证传入圈号就是当前圈，迟到任务理论上可以修改错误圈；
8. 文件导出失败后若数据库终态也失败，写盘器仍在 `finally` 清空内存活动圈。

这些路径都可能在磁盘或调度故障时重新制造 `running` 孤儿圈，随后表现为“上一圈尚未封存”、反复自维护和无法重新进入试验。因此 V2.12.0.5 保留为阶段性历史候选，现场验证版本迭代为 `V2.12.0.6`。

## 2. V2.12.0.6 的最终不变量

所有正式圈、报警圈、学习圈、资格圈和软件恢复圈统一满足：

`圈身份匹配 → 封闭截止窗口 → 排空 Raw 发布管线 → 等待真实耐久前缀 → 提交唯一终态 → 清除圈身份`

若任一步失败：

- 保留活动圈号、尝试号和写盘器当前圈；
- 保持通道安全断能并进入 `Recovering`；
- 通过有界退避持续重试；
- 不计完成次数、不开始下一圈、不允许正式重入；
- 不把软件/磁盘故障升级为卡钳永久故障。

## 3. 代码整改

### 3.1 所有恢复旁路接入耐久门禁

- Timer 看门狗先捕获圈号和截止时间，在恢复循环中等待耐久收口成功后才重建 Timer 并重入。
- 受影响组硬期限清场先统一断能和机械释放，再等待组内圈耐久收口；失败保持断能并由持续组级恢复重新调度。
- 活动圈上限使用事件携带的精确 EPB/圈号，通过耐久门禁后才作废并重置液压代次。

### 3.2 正式圈失败不再“无屏障 Abort”

- `FinalizeCyclePersistence` 改为调用统一 Raw/耐久前缀屏障，不再只比较 `LastPersistedSequence`。
- 删除“屏障异常仍优先提交作废终态”的降级语义。
- 正式圈 Complete/Abort 失败时保留圈身份，暂停 Timer、断能、退出液压成员，并交由持续基础设施恢复清场。
- 普通周期回调的 `ClearCurrentCycleNumber` 会拒绝清除仍登记为“等待耐久恢复”的圈。

### 3.3 报警、学习和资格圈一致收口

- 报警圈终态失败后保持映射，并按 1/2/5/10/30 秒退避持续重试；不再写一个未经耐久确认的 `failed` 终态。
- 学习/资格圈在导出和封存前同样等待 Raw/耐久前缀。
- 文件导出失败后只有数据库失败终态确实提交成功才清空活动圈；数据库也失败时抛出可恢复异常并保留圈。

### 3.4 写盘器拒绝迟到终态覆盖

`EpbDiskWriter.CompleteCycle`、`AlarmCycle`、`AbortCycle` 现在必须确认 `CurrentCycle == expectedCycle`；SQLite 终态更新还必须恰好命中一条记录。迟到任务、错误圈号或缺失索引都会明确失败，不再静默覆盖或清除新圈。

### 3.5 Stop/重新开始门禁覆盖全部恢复任务

逻辑清场的 `SoftwareRecoveryCount` 现同时计入 Timer 恢复、活动圈上限恢复、报警圈终态重试、正式圈耐久待处理及仍登记的活动圈。只要任何任务或待处理圈尚未收口，Stop 就不能把同进程状态判为可重启。

Stop 在撤销运行授权前、后各捕获一次活动圈，单调收紧截止窗口，覆盖“停止刚开始时正在创建圈”的窄竞态。整台设备 Raw 排空、队列清零和耐久边界确认后，才提交这些圈的停止终态；终态提交失败、Recorder 不可用或提交后内存圈身份发生变化，均保留身份并拒绝同进程重启。所有恢复退避延时绑定批次取消令牌，人工停止不再被最长 30 秒的后台休眠拖住。
