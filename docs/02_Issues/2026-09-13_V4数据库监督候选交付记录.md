## 2. 已落地的修改

1. 未重入成员只清理自身，不再把整组已恢复成员一起改为 StartBlocked；旧批次/其他恢复所有者的状态不由旧 finally 覆盖。
2. 进程必须重启的锁存贯穿停止生产结果和最终事务投影。硬件已经安全停止，不再被误解释为控制进程已经可以继续工作。
3. 数据库按应运行通道独立观察 completed 提交，每 5 秒读取，失败归 Unknown；90 秒或六周期阈值后需要三轮成功确认。读取子进程具有两秒期限、256 MiB 上限，正常退出竞态不再误报读取失败。
4. 原快照缺失、RunActive 清空后继续观察已绑定数据库。外围监控脚本不再因原快照失效而禁用观察器；观察器退出后只按原绑定重新启动观察器。
5. 数据库停滞请求能够进入原受控安全接管入口，保留单一启动许可、人工停止否决、旧进程退出证明和安全联锁。重启后的成功判断要求全部应运行通道的新提交和动作证据，不以进程存活替代。
6. 新人工批次绑定新的 RunId/RunEpoch 和隔离代次；旧停止记录、旧待处理请求不得带入新批次。
7. 补 Sidecar 启动通道连接、发送及完整应答合计三秒截止；补正式圈收尾诊断以及已释放子窗不再等待遗漏的 FormClosed 事件。
8. 一键包增加独立监督启用、禁用、查询、卸载入口和 SQLite x86 依赖，保留原 Base 及安装/修复/卸载结构。

原采样门限、断能及泄压阈值未放宽；没有重置计数、检查 CAN 或改写 WJ-EPB 项目数据。
