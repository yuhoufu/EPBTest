# V2.14.2.12-rc.2 人工停止后的快速关闭

## 范围与操作语义

本轮仅修订人工关闭流程，基于 `2.14.2.12-rc.1`，程序版本仍为 `2.14.2.12`。既有采集、报警门限和故障恢复策略不调整。旧标签及候选包保留，新候选通过提交摘要和 `2.14.2.12-rc.2` 标签区分。

| 场景 | 当前行为 |
| --- | --- |
| 运行、启动或恢复尚未人工停止 | 两个关闭入口拒绝关闭并提示先停止；判定先于退订事件、清理恢复任务和退出计时 |
| 人工停止但安全凭证不足 | 保持界面；不能用停止按钮标记、初始零值或陈旧样本替代安全确认 |
| 人工停止且安全确认 | 隐藏监控界面并保留消息循环完成收尾；主界面仍保留 |
| 主程序关闭且各监控允许退出 | 隐藏主界面，必要的后台保存完成后才结束主进程 |
| 未开始试验且无活动资源 | 允许快速关闭，不要求现场采样 |
| 后台尚未收尾又请求打开监控或开始 | 拒绝创建新会话，避免资源竞争 |

“快速关闭”是可见界面离开；写盘被阻塞时，隐藏窗体及其资源仍由收尾任务保留，不承诺此时任务管理器中主进程已经消失。Supervisor、SessionAgent 及登录任务保留；不会因此恢复试验。

## 代码与安全证据

- 共用人工关闭判定；故障看门狗拥有的恢复退出仍走原路径。
- 人工停止命令绑定 StopAll 的 TransactionId、RunId、RunEpoch 和 Generation；允许人工停止显式采用同一故障停止事务，不能凭历史停止结果关闭新批次。
- 在停止流程的物理边界只读记录电流及压力证据。电流采用对应执行器原有的有效断电阈值，保留其基线补偿；压力采用项目泄压阈值。电流须为有效、100ms 内的新鲜控制样本，时间不得早于 DO 完成；压力须符合原配置的新鲜度及停止后的采样时间。
- 安全凭证只有在执行授权撤销、生产者和执行对象冻结、DO/电源及液压安全回执成立时形成。DAQ 停止后仅复用当前冻结事务中已确认的凭证，不将停止前的显示值当作实时安全事实。
- 后台收尾加入已存在的持久化任务，并只对冻结边界进行保存重试；不重新执行物理 StopAll，不扩大数据边界，不解除禁止重新启动标记。数据或圈终态仍未闭合时保留任务。
- 人工关闭不启动原有 3/30 秒本地强杀计时。最终落盘收尾完成后才发布兼容的一次性退出回执；故障替换退出的许可和截止机制不变。
- 正常人工关闭通知绑定捕获的精确 Watchdog 会话；最终清理仍使用既有身份校验。没有通配杀进程、重置计数或删除恢复证据。
