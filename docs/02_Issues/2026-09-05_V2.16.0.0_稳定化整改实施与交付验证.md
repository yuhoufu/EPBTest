## 5. R28 安装、迁移、清场与回退

正式包保留 R27 外层入口 + `Package` 结构，另加“一键停止全部相关进程”“恢复后台服务”“一键故障采证”及现场验证表。外层 `bundle-identity.json` / `快捷部署包身份.json` 内容相同；`SHA256SUMS.txt` / `快捷部署包-SHA256.txt` 内容相同。外层 `SHA256SUMS.txt` 与内层 `Package/SHA256SUMS.txt` 分别封存工具与程序；八个正式组件及其 PDB 哈希记在 build-identity 中。

安装器采用 Windows PowerShell 5.1、UTF-8 BOM 脚本、ASCII/CRLF CMD、明确 UTF-8 JSON。UAC 子进程等待结束并传播退出码；取消提权返回非零。来源包预检通过才停止旧后台；同版本按完整身份换包；staging 先校验再切换 Current，旧目录保留，换包事务支持中断重试。`.NET Framework 4.8`、x86 `nicaiu.dll` 与安装卷空间是实际预检项，硬件功能仍需现场验收。

升级保留 ProgramData 现场配置，旧检查点仅迁移项目/通道和剩余正式圈。旧许可、nonce、执行会话封存，不迁移上电授权。校准、DO 映射、PSU 地址和报警阈值必须在现场启动前逐项核对。旧检查点缺少安全证据时安装明确受阻；仅在操作人员真实完成物理隔离后使用文档中的 `-PhysicalIsolationConfirmed`，该参数只记录人工确认。

清场先持久写维护禁止启动标记，主程序与 Supervisor 启动入口均读取该标记；允许安全组件完成断能。默认 45 秒内等待本次退出回执，校验 PID/启动时间、MotorsOff、PowerOff、PressureSafe、PersistenceDrained、LogicalQuiescent 与禁止续跑意图，再停止后台及精确路径进程。安全不明返回 10、身份不明 20、后台失败 30、残留 40。没有活动硬件 owner 的幂等清理会明确标为 `NoActiveHardwareOwnerObserved_NotPhysicalProof`，不能把它作为硬件断能证据。

恢复后台先校验安装包、封存旧会话，再恢复服务/任务；不启动机械试验。清场与恢复结果保存在 `%ProgramData%\MTTFTest\last-maintenance-result.json`。生产数据、数据库、配置和事故证据保留。采证工具另输出 evidence-summary.json；Complete=false 表示存在权限或大小限制等缺口，导出结束不等于证据完整。

回退步骤：安全停止 → 一键采证/数据封盘 → 备份 ProgramData 与项目检查点 → 停后台 → 由工程人员恢复已验证的同架构旧包或保留的 `.retired-*` → 用匹配安装工具重建后台 → 待机核对配置与次数。V2.14.2.11 只保留为工程回退来源，不自动晋升 LastKnownGood。跨 V2/V3 或许可契约回退不能直接复制活动状态。
