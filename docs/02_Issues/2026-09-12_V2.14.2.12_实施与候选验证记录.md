## 已实施的修复

| 问题与证据 | 修复 | 安全边界 |
| --- | --- | --- |
| I12 同一 SHA-256 因字符串大小写不同被安全代理启动身份校验拒绝 | 摘要按 64 位十六进制数值比较；覆盖 Supervisor、Watchdog 和 SafetyAgent 快照绑定 | 真摘要不同、无效长度/字符仍拒绝；nonce、会话及许可继续精确匹配 |
| 等待旧进程退出期间回执可被推进，随后使用等待前副本登记启动 | 退出后重新读取精确 handoff，revision 改变则重新评估；回执读改写用跨进程互斥门串行化；幂等重放保持原时间戳 | 不降低 revision，不覆盖同 revision 不同内容，不自动合并安全阶段 |
| I13 内部重建启动取消被当作 StartupRollback 撤销续测意图 | 绑定清理 RunId/Epoch；恢复子链取消按内部系统故障收尾；停止通知携带事务所属 RunId | 人工停止仍独立撤权；迟到旧事务不能借当前可变 RunId 撤销新批次 |
| 正式 Running 状态发布早于实际定时器建立 | 先建立执行体再发布 Running；首个回调等待发布完成，避免反向竞态 | 创建失败取消等待门并进入安全回滚，不能发布虚假运行状态 |
| I14 StopAll 已将通道切到新 Epoch，旧 DAQ context 终态不断被拒绝 | 验证同 Run 的 StopAll 所有权、冻结生产者、逐通道 DO 完成/兜底回执及电源 OFF 结果后，允许旧 DAQ 事务让出终态 | 不把默认 MotorOk 当作证明，不回写新代通道状态；旧事务以 Cancelled 释放 context/registry，Recovered 保持 false |
| I14 冻结前缀与终止水位闭合，但 Paused 被要求变为 Recovered | 仅冻结停机边界允许 Paused；其余水位、队列、丢弃、持久化阻塞和尾部终态检查保留 | 正常运行恢复仍要求 Recovered，排空不等于动作恢复 |
| 卸载会直接强制结束主程序/安全代理，同版本损坏无法修复 | 活动主程序/安全代理或未确认关闭时拒绝卸载；同版本比较不可变文件摘要；保留 ProgramData 配置和项目数据 | 查询权限不足时失败；不通配强杀，不用删检查点/计数解锁 |
| PowerShell 5.1 对无 BOM 的中文发布脚本解析失败 | 发布及新增脚本使用 UTF-8 BOM；cmd 使用 ASCII 和显式宿主/自身路径 | 不依赖 PowerShell 7 或开发机当前目录 |
| jxcq 实测重复安装失败：sc.exe 丢失服务路径引号；Stop-ScheduledTask 不支持 Confirm | 通过 Invoke-CimMethod 结构化写入并核验服务路径；移除不支持的参数，加入部署契约回归 | 只接受精确匹配本安装的服务路径；程序或安全代理活动时拒绝卸载 |
| 状态/采证的 PS 5.1 与 x86 SQLite 参数绑定失败 | 显式字符串转换；无快照请求时省略空 SnapshotPath 参数；SQLite 在线备份后执行 integrity_check | 状态/采证失败返回非零，不伪报成功，不将历史计数当作当前动作推进 |
