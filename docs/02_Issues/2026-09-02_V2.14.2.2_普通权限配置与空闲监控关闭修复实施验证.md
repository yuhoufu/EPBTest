# V2.14.2.2 普通权限配置与空闲监控关闭修复实施验证

## 问题结论

正式安装目录 `C:\Program Files (x86)\MTTFTest\Current` 应只承载程序和默认模板，不应承载运行时写入。此前监控窗初始化会原子写回 `Current\Config\TestConfig.xml.tmp`，因此桌面快捷方式以普通权限启动时必然可能收到“访问被拒绝”。

另一问题是监控窗关闭没有区分“仅初始化了本地资源”和“已经开始活动试验”。未开始试验也进入完整 `StopAll`，会尝试处理程控电源和 Watchdog 安全事务，导致无实际电源的电脑等待完整关闭期限。

## 已实施修复

### 运行配置目录

- 新增统一的 `RuntimeConfigPaths`：
  - 正式安装运行使用 `C:\ProgramData\MTTFTest\Config`；
  - 仓库或开发目录直接运行继续使用 EXE 相邻的 `Config`；
  - `Current\Config` 只保留为安装模板和升级迁移来源。
- `TestConfig.xml`、`UIConfig.xml`、`AIConfig.xml`、`AOConfig.xml`、`DOConfig.xml`、`PowerSupplyConfig.xml`、`AlarmConfig.xml`、`UnattendedAlarmConfig.xml` 的主程序读写入口已统一到运行配置目录。
- Watchdog 创建 SafetyAgent 安全配置快照时读取同一运行配置目录，避免主程序和后台安全组件使用不同配置。
- 主界面创建前校验目录是否存在、必要文件是否齐全并可创建/删除临时文件。正式安装校验失败时进入一次管理员维修；维修后原进程仍以普通权限运行。

### 安装、升级和快捷方式

- 首次安装把默认 XML 复制到 ProgramData，并把 `C:\ProgramData\MTTFTest` 授予 Authenticated Users 修改权限。
- 升级时若 ProgramData 中尚无某个文件，优先从旧 `Current\Config` 迁移；旧目录也没有时才使用新包模板。
- 已有 ProgramData 配置不覆盖，只补缺失文件。
- `Current` 继续为普通用户只读；桌面和开始菜单快捷方式直接指向 `Current\MTTFTest.exe`，未设置管理员运行。
- 安装脚本比较程序集版本：当前槽完整且版本不低于来源时保留 `Current`，不会再次生成 `.retired-*`；新版本或组件缺失才替换程序槽。
- 从外部解压目录启动同版或旧版 EXE 时，若已安装版本健康，直接转到已安装 `Current`。

### 监控窗生命周期与关闭

监控窗增加 `Initializing`、`Idle`、`Running`、`Stopping`、`InitializationFailed`、`Closed` 六种状态。

只有存在活动批次、已经尝试上电或已有 Stop 事务时才进入完整 `StopAll`。`Idle`、尚未上电的 `Initializing` 和 `InitializationFailed` 使用快速关闭：

- 不连接、不查询、不关闭程控电源；
- 停止并释放已创建的 Dev1/Dev2 采集资源、DO/AO 本地控制对象、UI 与落盘定时器；
- Flush 已接收的本地 DAQ 数据并释放写盘器；
- 解绑事件并释放已存在的 Watchdog UI 会话；
- 重复点击关闭只加入既有关闭流程，不重复执行硬件释放。

空闲会话的 Watchdog 非安全性清理重试窗口限制为 2 秒，避免沿用活动试验的 15 秒会话收口等待。

初始化异常对话框确认后会自动请求关闭监控子窗；未创建成功的对象均通过空值保护跳过。

主程序空闲退出的最终硬截止为 3 秒。活动试验保持完整安全停机，10 秒时记录目标超时诊断；仅持久化或既有安全交接允许继续等待，30 秒为进程退出最终硬截止。

### 活动试验电源断联语义

- `PowerSafetyDisableOutcome` 增加 `CommunicationUnavailableSkipped`。
- `StopSafetyResult` 分离真实 `PowerOffConfirmed` 与 `PowerShutdownSatisfied`。
- TCP/命令通讯不可用可满足本次退出条件，但 `PowerOffConfirmed` 始终保持 `false`，日志保留“断电未真实回读确认”。
- 内部 Power Gate 超时、遥测 owner 未退出、明确回读 `OUTP ON` 均不能归为通讯跳过，仍进入安全接管路径。
- 启动试验的电源预检没有放宽；无实际程控电源仍不能开始试验。
