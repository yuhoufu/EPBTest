## 2. 安全停止与退出

1. 在正在运行的监控窗口点击“停止试验”。运行中直接关闭会被拒绝，这是既定安全行为。
2. 等待该停止事务的电流断电、程控电源关闭、液压释放、数据保存和逻辑收口完成。值缺失、过期、压力未释放或后台落盘未完成时，停止更新操作。

4. 核对匹配该PID和启动时间的 application-exit 回执：GracefulCompleted，MotorsOff、PowerOff、PressureSafe、PersistenceDrained、LogicalQuiescent均为true，RelaunchDisposition=Forbidden。

## 7. 失败处理与回退

- 安全停止未完成：保留所有保护组件，不更新、不强杀。
- 新包安装失败：保留安装日志、Current和retired目录，不反复卸载删除证据。
- 新程序不能通过安全准入或不推进：通过同样的人工停止和安全退出流程收口后，再决定回退。
- 回退前从当前新包禁用并卸载独立监督，确认交还。安装器不会用普通Install覆盖更高版本。需要回退时，在确认安全退出和独立监督交还后，使用新包的“一键卸载.cmd”移除程序安装，再从核验过的旧包执行安装。卸载只针对程序目录和服务/任务，保留ProgramData与项目数据。安装前后再次核对六通道历史次数。不能假定直接运行旧安装cmd就已经回退。
