## 1. 取证方法

- 输入只限用户指定的 13 份封盘。JSON 以 UTF-8（允许 BOM）读取，日志优先 UTF-8。
- 会话事件合并范围：各封盘直接 `WatchdogSessions/*.sidecar-events.jsonl`；以 SessionId + EventId 去重，不把 LegacySealed 镜像重复计入。
- 源文件已滚动且备份为增量；统计仅表示所给文件可见的不同事件，不是全部历史事件总量，也不是事故次数。
- 所有时间换算为 UTC+8。SQLite 使用 URI 参数 `mode=ro&immutable=1` 打开封存的静态快照。
- 数据库结构检查仅证明 SQLite 结构可读，不等价于完整波形链、计数口径或停机证据全部通过。
