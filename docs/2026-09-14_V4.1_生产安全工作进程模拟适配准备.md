# V4.1 生产安全工作进程模拟适配准备

完整独立执行链路需要跨进程运行生产安全命令与回执协议。当前正式 SafetyAgent 命令行固定实例化真实硬件工厂，无法在无硬件 jxcq 上验证正向安全阶段；此前模拟直接给状态机回执，不能代替生产工作进程。

本次把 IndependentSafetyWorker.Run 的硬件工厂作为内部重载参数；原单参数正式入口仍固定调用 ProductionSafetyHardwareFactory。没有新增环境变量、配置或命令行开关将正式 SafetyAgent 切换到模拟。测试程序集通过友元访问内部重载，继续执行 SYSTEM 检查、受保护命令/配置摘要校验、期限、精确进程身份和原回执写入。

仅 IndependentRecovery.ProcessTests 新增 `--independent-stage` 测试路由：要求受保护配置目录内的 `SIMULATED-HARDWARE-ONLY.txt`（最多 128 字节），允许 success、pressure-failure、hang 三种测试工厂行为。正式程序和安装包不引用这个测试类。上述模拟不能证明真实电源、DO、AO 或压力已经安全。
