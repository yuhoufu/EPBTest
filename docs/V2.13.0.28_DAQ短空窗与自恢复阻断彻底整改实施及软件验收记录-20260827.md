## 1. 结论

本次以包含 V2.13.0.27 未提交修复的工作区为基线继续迭代，没有回退已有改动。两份源分析文档所确认的故障链已经在软件层逐段切断：

`DAQ 短空窗 → 静态槽缺员 → 阶段身份丢失 → 活跃任务误判孤儿 → 30 秒反杀 → 看门狗丢失 RunId → 人工重启`

V2.13.0.28 已完成以下软件验收：Debug x86 和 Release Any CPU 全量构建通过，AdaptiveControlTests 610/610、EpbDiskWriterTests 55/55、PowerSupplyDebugger.Tests 17/17 全部通过，版本身份、关键故障注入、10,000 次公共槽合成竞态、看门狗持久恢复意图和冗余断电证明均通过专项验证。

该结论表示“计划内软件整改已落地且回归通过”，不等同于“现场稳定性已经最终验收”。正式判定稳定仍须完成第 9 节的现场长稳验证。

## 3. 最终生效参数

| 参数 | 默认值 | 行为 |
| --- | ---: | --- |
| `DaqLivenessWarnThresholdMs` | 250 ms | 未带电限频告警；带电高优先级 OFF 并作废当前动作 |
| `DaqLivenessSuspectThresholdMs` | 1500 ms | 建立 Device + RunId + Generation 恢复资格栅栏 |
| `DaqLivenessTripThresholdMs` | 5000 ms | 连续陈旧或 NI 明确错误时仅重建对应 DAQ task |
| `GlobalFormalSlotAdmissionWindowMs` | 300 ms | 正式公共槽实际到达后的动态准入窗口 |
| `RecoveryOrphanGraceMs` | 10000 ms | 精确任务和有效 owner 均缺失后仍需满足的无进展宽限期 |
| `InProcessRecoveryNoProgressMs` | 60000 ms | 无材料进展后允许外部安全接管 |
| `InProcessRecoveryMaxTotalMs` | 300000 ms | 单次进程内恢复总期限 |
| `EpbPowerSupplyOffProofThresholdA` | 0.5 A | 新鲜电源遥测确认断电的组电流上限 |
| `EpbPowerSupplyOffProofMaxAgeMs` | 1000 ms | 电源遥测可用于断电证明的最大年龄 |

DAQ 三档阈值的配置读取不再采用 `min=max`。程序只接受正数且严格满足 `Warn < Suspect < Trip` 的工程参数，并在启动日志与 checkpoint 的 `EffectiveRuntimeSafetyParameters` 中记录最终生效值，便于封盘追溯。

## 4. 关键代码行为

### 4.1 DAQ 分级与设备资格栅栏

- 250 ms Warn 不再启动恢复链。带电时先断 DO，再作废动作和退出当前槽；未带电只限频记录。
- 1500 ms Suspect 为同一 Device、RunId 和 Generation 下的必需通道建立资格栅栏。稳定数据观察、供电检查和机械重新资格全部完成后，才允许相关通道加入未来正式槽；单一通道不能提前清除设备栅栏。
- 5000 ms Trip 只有在连续监督确认或 NI 明确报错时重建对应 DAQ task，不重启液压、整批或进程。
- StopAll、DAQ 重建阶段、液压释放/建压、学习机械圈、资格完成和正式定时器提交均刷新材料进展。

### 4.2 正式公共槽

- 正式阶段使用动态 Join/Skip/Admitted；学习和资格阶段继续使用完整固定成员。
- 恢复中、已取消或未完成资格的通道对当前槽显式 Skip，不进入必须到达集合。
- 窗口关闭后的迟到通道不获得当前液压 lease，只能从下一槽重新加入。
- Join、Skip、Cancel 和重复 Skip 使用幂等状态转换，所有竞态均能收敛，不保留静态缺员。
- 某液压组失败只回退本组；已完成动作的健康组保留并提交当前周期。

### 4.3 恢复身份、覆盖与安全交接

- `HydraulicRecoveryIntent` 固定携带 `SourcePhase、OwnerKind、TargetPhase、RunId、RunEpoch、IncidentId、OwnerId、HydraulicId、Channels`。
- 阶段映射为：PreRelease/SingleChannel → Startup，Learning → Learning，Qualification → Qualification，Formal → Formal。
- 精确活跃任务覆盖优先于可变 owner 投影。owner 投影短暂缺失时由不可变任务契约自修复，禁止派生 Orphan、终态清场或外部恢复。
- 孤儿必须同时满足无精确任务、无有效 owner、progress token 至少 10 秒不变，并在连续复查后仍成立。
- `ExpectedOutputDisabled` 表示等待唯一电源恢复 owner，不计入定位、学习或硬件失败次数。
- 外部接管严格按“取消恢复 worker → 有界等待 → 安全清场 → 撤销 permit → 请求外部接管”执行，禁止在机械学习动作中途直接断权。

### 4.4 Watchdog 证据链

- `LastVerifiedActiveRun` 只接受身份验证通过、RunActive=true、RunId 非空且进程角色为 InitialProcess 的心跳。
- 持久化 RunId/Epoch、PID/启动时间、所选通道、恢复资格、完成/人工/永久隔离列表、心跳序号和匹配 checkpoint 身份。
- 首次恢复意图依次选用：`LastVerifiedActiveRun`、最后有效活动心跳、身份匹配且 Armed 的 checkpoint mirror。
- 瞬态 DAQ/学习隔离不进入冻结排除列表；排除仅包含已完成、人工排除和有权威证据的永久硬件隔离。
- 全部通道完成时正常解除 armed；全部永久硬件故障时保持安全 idle；身份、hash、PID/checkpoint 冲突或无法证明输出安全时继续 fail-closed。

### 4.5 冗余断电证明

- DO OFF 成功且 DAQ 新鲜低电流：确认断电。
- DAQ 陈旧，但电源遥测在 1000 ms 内且组电流不高于 0.5 A：确认断电，不触发电源组联锁。
- DO 失败、DAQ 与电源遥测均不可用/陈旧，或新鲜电流仍高：关闭关联电源组。
- 电源应急 latch 的建立和清除都携带 incident/generation；旧事务不能清除新事务建立的 latch。
