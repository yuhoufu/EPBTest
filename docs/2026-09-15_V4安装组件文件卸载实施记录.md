# V4 安装组件文件卸载实施记录

## 已实现部分

文件安装器新增 `Remove-IndependentOwnedComponents`，供完整卸载流程在持有维护权、执行器租约及确认组件已注销后调用。当前尚未接到顶层 Uninstall；不能将本次函数测试称为完整文件卸载通过。

函数不扫描目录猜测归属，只处理原安装清单给出的程序组件。要求规范路径位于安装根内的 Current、FallbackGuard 或 Tools，扩展名为 EXE、DLL、PDB、PS1 或 EXE.config；配置目录全部排除，斜线和反斜线两种路径均处理。拒绝越界、重复路径、重解析点、原文件已变成目录、文件摘要不一致等情况。

在删除任何文件前检查整批候选。文件内容有变化时保留并报错，不以模糊进程名或目录扫描清空程序目录。删除前再次核对摘要；重复调用容忍组件已缺失。不会递归删除安装根、项目数据库、配置或未知文件。

## 本地验证

`Tests/IndependentRecovery.ProcessTests/Test-OwnedComponentRemoval.ps1` 在 Windows PowerShell 5.1 x86 下 exit 0，使用主仓库 Codex 下的实际隔离文件验证：

- 后一个组件摘要变化时，前一个有效组件也未提前删除。
- 有效 EXE/DLL 移除，重复调用正常。
- 配置目录中的 DLL、数据库和未登记 DLL 内容保持。
- 越界路径、两种分隔符的配置路径以及数据库路径被拒绝。

证据为主仓库 `Codex/v41-owned-removal-test.log`。本轮未在 jxcq 执行文件删除，未操作 WJ-EPB。
