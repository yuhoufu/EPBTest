## 使用示例与限制

正常升级前必须人工安全停止并退出原主程序，保留原构建完整包。以下命令在新包目录运行，路径为示例；不允许用首次安装覆盖已有安装。

```powershell
.\Install-AutomaticRecoveryBundle.ps1 -Mode ValidateUpgrade -InstallRoot 'C:\Program Files (x86)\MTTFTest' -PreviousBundleDirectory 'D:\旧版完整包'
.\Install-AutomaticRecoveryBundle.ps1 -Mode Upgrade -InstallRoot 'C:\Program Files (x86)\MTTFTest' -PreviousBundleDirectory 'D:\旧版完整包'
.\Install-AutomaticRecoveryBundle.ps1 -Mode RollbackUpgrade -InstallRoot 'C:\Program Files (x86)\MTTFTest' -PreviousBundleDirectory 'D:\旧版完整包' -TransactionId 'Upgrade目录中实际32位事务ID'
```

升级/回退成功仅代表安装状态切换完成。启用监督和开始试验仍需明确操作及原安全预检。此为完整包正常路径及重复回退验收，尚未覆盖每个阶段强制中断、已有暂停/隔离运行意图迁移、交互 UAC、完整恢复故障注入矩阵和真实电源/液压/继电器验收；候选 tag 和最终现场交付审查仍未完成。不能将安装回退成功当作无人试验恢复成功。
