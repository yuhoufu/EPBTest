## 行为

沿用监控界面已有明确确认，以及控制器已有通道未上电、无运行计时器/执行器/周期尝试的检查。在清理项目 XML 报警之前，先更新独立持久意图：解除该通道永久隔离、保存选择状态，同时将它加入暂停集合。

解除永久报警不等于开始试验。后续仍需明确开始及原有完整预检。若 XML 更新失败，持久暂停仍阻止自动续测；下次正常启动若读到 XML 旧锁存，也会重新导入该隔离。

运行中的项目只允许当前精确控制者执行此事务；整批已经人工停止且未 Armed 时，允许同安装可执行文件的新主界面处理旧隔离。主程序先校验项目配置身份；事务使用当前修订号 CAS，拒绝旧修订、维护模式、安全清理或未完成的独立接管。解除操作不修改整批人工停止/暂停，也不清零试验计数。

## 实现入口

- `IndependentProjectStateStore.ResetPermanentExclusionForOperator`：原子更新与审计。
- `IndependentRecoveryStartup.ResetPermanentExclusion`：当前项目、批次及配置核验。
- `EpbManager.ResetPermanentAlarm`：在原有安全检查后、XML 保存前调用持久事务；不新增自动解除入口。
