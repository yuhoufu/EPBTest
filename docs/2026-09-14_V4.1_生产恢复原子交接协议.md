# V4.1 生产恢复原子交接协议

状态：协议与文件存储已实现并完成本地回归；SYSTEM 宿主、主程序启动入口和安装程序仍需接入。本文不表示完整恢复交付完成。前序 jxcq 结果对应旧提交，不能用作本轮新增协议的远端验收。

## 为什么调整第一阶段的存储方式

第一阶段分别保存运行意图和恢复事务。若替代进程消费凭证后，更新运行意图和事务的两个写入之间发生崩溃，就可能留下新旧 RunId 混合状态。仅增加两个文件各自的修订号不能保证整个交接原子完成。

新增 `Watchdog.Protocol/IndependentProjectState.cs`，生产交接使用 `independent-project-state.json` 单一聚合文件保存：

- 维护模式、状态总修订号及安全清理待办。
- 当前运行意图及其修订号。
- 恢复事务、阶段、请求、代际和替代进程身份。
- 当前控制进程的 PID、启动时间、可执行文件、Windows 会话及独立会话标识。
- 一次性启动凭证、摘要、期限、目标交互会话及消费者身份。
- 最近 32 条操作来源、通道选择前后值、运行身份和原因审计。

每次修改都在同一跨进程互斥锁内重新读取状态，核对总修订号，再以原子文件替换提交整个聚合状态。不能用上一次读取的副本覆盖新的人工操作。互斥锁允许 SYSTEM、Administrators 和创建者访问；生产目录和配置仍必须由安装程序施加 ACL，JSON 和互斥锁本身不能替代文件权限边界。

## 交接规则

1. `ArmManualRun` 创建新批次；维护中、安全清理未完成或恢复事务未结束时拒绝新批次。普通重新开始保留永久隔离。
2. `BeginRecovery` 将恢复事务和 `SafetyCleanupPending=true` 一次性提交。
3. 人工停止、暂停或取消勾选递增意图修订号并撤销已有凭证。**不能同时清除安全清理待办**；已经开始的安全清理仍须由宿主完成。
4. `IssueLaunchTicket` 只允许在 `LaunchPending`、安全清理完成、授权仍一致且未处于维护模式时调用。凭证绑定目标交互会话，Session 0 不能作为主程序恢复启动目标。
5. `ConsumeLaunchTicket` 同时保存消费记录和替代 PID/启动时间。摘要、期限、会话、路径、当前修订号不一致时拒绝；同一个凭证最多消费一次。
6. `CommitReplacementRun` 在同一次提交中更新意图 RunId/RunEpoch、事务 RunId/RunEpoch、意图修订号和当前控制进程绑定。消费后人工停止，或者已经超过阶段期限，均不得提交新运行批次。
7. 凭证消费者崩溃，不重新开放已经消费的凭证。宿主必须按原事务的明确阶段处理失败与重试，不得凭进程消失重新发放旧许可。

反序列化显式要求安全清理、维护、停止、暂停和凭证撤销等字段存在，并检查布尔类型，防止缺失字段被默认为“允许”。审计限制条数及字符串长度，避免中文长原因使 64 KiB 状态文件上限阻止后续人工停止。

## 本地验证

证据位于仓库根 `Codex/`：

- `v41-state-solution-build.log`：Debug x86 解决方案构建。
- `v41-state-tests.log`：原有工作进程 5 项、原子状态 22 项。
- `v41-state-fallback.log`：恢复安全专项 74 项。

新增验证包含两个真实进程竞争同一个凭证，要求恰好一个成功；消费进程结束后，从磁盘重新打开状态仍拒绝旧凭证。其他覆盖包括：安全清理前禁止发证、错误摘要、凭证过期、Session 0 拒绝、人工撤销并发、旧修订号、消费后停止、重复提交新批次、永久隔离保留、选择前后审计和缺失安全字段拒绝。

测试中的安全阶段推进为模拟，不执行硬件动作，不证明独立硬件安全确认已完成。

## 后续接入约束

- SYSTEM 宿主和主程序必须使用本聚合状态作为生产交接源，不能并行使用第一阶段两个文件作为另一份有效授权。
- 宿主从受保护安装配置确定项目、数据库、程序摘要及交互任务，不接受用户可写文件提供的任意 SYSTEM 命令。
- 对人工撤权的事务，宿主仍要处理未完成安全清理，但不能继续消费或生成旧启动许可。
- 实际 PID、启动时间、可执行路径和交互会话必须在操作系统中复核；协议字段并不是进程真实性证明。
- 旧 Watchdog 与新执行器必须共享执行权约束。主程序运行前和旧控制者上电前的撤权检查尚须接入，不能仅依赖 UI 心跳。
- 需要在 jxcq 的交互会话中重跑凭证竞争和整链测试；主程序凭证拒绝 Session 0，不能把 SYSTEM 测试进程冒充交互主程序。
- 接通后仍须完成三个正式周期落盘验收、服务与任务安装/修复/卸载/回滚、统一版本和完整 7z 安装包；真实硬件确认另列台架验收。
