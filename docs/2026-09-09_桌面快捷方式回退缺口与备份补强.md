# 桌面快捷方式回退缺口与备份补强

## 源码事实与现场结论边界

`Tools/Install-MTTFTest-Unattended.ps1` 的原 `Install-Shortcuts` 按固定名称删除 V2.14、V2.17 入口，再根据 Current 下 EXE 版本生成新名称。原流程没有保存被删除/覆盖的完整快捷方式，也没有对应回退恢复事务。仅恢复 Current 文件不会自动恢复已删除的旧入口，亦不会自动删除新版名称入口。

这是源码可证明的故障机制，不是 wj-epb 当次事故的已确认根因。还需原安装命令、执行账号、桌面/开始菜单原链接、实际目标和回退记录来确定现场是否走过该路径。

## 本次补强

- 同名不再等于属于本安装：只有目标为当前安装目录内 Main/Watchdog 的旧入口才会被清理；同名新入口指向其他目标时，拒绝覆盖。
- 后续复核进一步收紧 Watchdog 入口：除目标路径外，参数必须精确匹配安装器生成的 `--launch-main --main-executable "本安装的 Main 路径"`。相同启动器配其他参数或其他 Main 的入口不视作本安装所有；未知参数形态不自动清理。
- 删除旧入口或覆盖现有入口之前，把完整 `.lnk` 保存到安装根目录的 `DeploymentShortcutBackups/<唯一ID>/original.lnk`，并记录原绝对路径、安装根目录、UTC 时间及 SHA256。
- 备份与原文件哈希一致才继续；备份文件和清单执行落盘刷新，再读回验证。失败则抛出错误，不继续该链接的修改。
- 完整字节保留启动参数、工作目录、图标、提权位等属性，避免仅重建名称或图标。

备份不在 Current 槽位内，普通槽位替换不会覆盖它；但卸载安装根目录前仍必须导出这些备份，不能把它当作独立于整目录删除的永久存档。

## 已验证

PowerShell 7.6.5 下真实 WScript.Shell COM 链接测试 4/4 通过：其他目标的同名入口拒绝覆盖；其他目标的旧名称入口保留；删除和覆盖前原字节及路径/哈希保全；新入口指向 Supervisor 并携带 Main 参数和工作目录。

日志：`artifacts/guard-physical-safety/test-deployment-shortcut-backup.log`。仅在 GUID 临时目录运行抽取的快捷方式函数，未运行安装器入口、未操作真实桌面、服务、任务或硬件；临时夹具保留。安装器语法解析及变更空白检查通过。未取得本次 Windows PowerShell 5.1 执行结果。

加入 Watchdog 参数归属检查后，同一隔离测试扩展为 5/5 并通过，日志 `artifacts/guard-physical-safety/test-deployment-shortcut-ownership.log`。新增反例证明同一 Supervisor 的无关参数不会触发旧链接删除；合法参数仍能完成原文件备份和新链接创建。本次未改运行期二进制，不重复此前已完成的控制/Guard 回归。

## 仍未完成

这不是完整自动回退事务：仍需绑定部署事务的一组链接清单、记录本次新增入口、在槽位回退后核验并恢复原链接、仅移除本次创建且未被用户修改的入口，以及处理不同执行账号/公共桌面。不得据本次测试宣称 wj-epb 桌面问题已经现场修复或整包回退已验收。

## 卸载归属检查补齐

卸载用 `Remove-Shortcuts` 现显式接收安装根目录，并复用相同的目标/Watchdog 参数归属检查，不再仅凭名称删除其他目标的入口。实际卸载调用点已传入安装根目录。

隔离 COM 测试扩展至 6/6 并通过：在前述安装及备份检查之后，调用卸载快捷方式函数，确认本安装新入口被移除、其他目标的旧名称入口原字节保留。日志 `artifacts/guard-physical-safety/test-deployment-shortcut-uninstall-ownership.log`。只删除测试夹具内刚创建的本安装链接，其先前原文件备份仍保留；没有卸载程序、触碰真实桌面或启动安装器入口。此结果不覆盖不同账号/公共桌面或完整卸载事务。

## 新建入口证据补充

快捷方式备份清单升级为 schemaVersion 2，显式记录 originalExists；安装目标原本不存在时，也必须先持久化不存在记录，backupFile/sha256 为空，不伪造原文件备份。已存在链接仍保留完整原字节。创建链接并设置提权位后，另以 CreateNew 写入 `created-link.json`，记录精确绝对路径及最终 SHA256，刷新落盘并读回核验；已有原备份清单不被覆盖。

隔离 COM 测试 **7/7** 通过，日志 `artifacts/guard-physical-safety/test-shortcut-created-evidence.log`。新增用例在 GUID 夹具内从无入口状态重新安装，验证不存在记录以及创建后文件哈希，未调用真实安装器入口或真实桌面。差异格式检查通过。

这只是完整回退所需证据的补齐，尚未实现消费这些证据的自动回退、整组部署事务绑定或并发用户修改保护。不能仅凭该记录删除后续同名链接；实际回退还须核验创建哈希/归属、恢复备份并处理崩溃窗口。未部署 wj-epb。

## 写入前版本复核

旧链接删除及目标链接创建/覆盖之前，现调用 `Assert-ShortcutUnchangedSinceBackup` 复核原绝对路径、schema、存在状态及原哈希；备份后已变化或原本不存在却已出现的链接拒绝修改。创建凭据前对最终 `.lnk` 调用 Flush(true)，避免仅刷新凭据文件而漏掉链接文件。

隔离 COM 测试 **8/8** 通过，日志 `artifacts/guard-physical-safety/test-shortcut-prechange-fence.log`。新增用例验证原状态可通过、修改后拒绝、不存在记录遇到新文件拒绝，以及检查不改变用户修改后的字节。测试仅操作 GUID 临时夹具。

该复核仍存在检查与 Shell Save/Remove 之间的竞争窗口，不是文件系统原子比较替换，也不是完整自动回退。后续需通过暂存文件、精确恢复策略与整组事务补齐；不能声称并发用户修改已完全受保护。

## 链接暂存发布

生成链接和写入提权位现改在目标同目录的唯一暂存 `.lnk` 完成，刷新暂存文件并校验启动归属后，再复核原状态。原目标存在时用 File.Replace 发布完整文件；原目标不存在时用不覆盖的两参数 File.Move，拒绝覆盖期间新出现的入口。发布后校验最终哈希并写创建凭据。

首次隔离运行因 PowerShell 把 Replace 的 `$null` 备份路径转换为空字符串失败，日志 `test-shortcut-staged-publication.log` 已保留；改用 `[NullString]::Value` 后原测试通过（`test-shortcut-staged-publication-v2.log`）。再增加成功发布不残留暂存链接检查，运行日志 `test-shortcut-staged-publication-v3.log`。暂存失败不自动删除证据文件，旧链接备份仍保留。

单文件完整发布不等于原子比较替换：已存在目标仍有最终复核到 Replace 之间的用户修改窗口；多入口操作、崩溃恢复与整包回退仍未事务化。测试只在临时夹具内，未触碰真实桌面。

## 同次安装的准备清单

Install-Shortcuts 现冻结目标路径列表，并给该次操作生成统一 transactionId。目标发布与旧入口退役的所有备份先完成，随后在安装根 `DeploymentShortcutTransactions/<ID>/plan.json` 持久化 Prepared 清单，绑定绝对路径、Publish/Retire 动作、各备份清单、安装根、账号及时间；计划读回校验通过后才允许删除旧链接或发布新链接。目标路径与旧名称重合时不重复退役同一路径。

隔离 COM 测试 **10/10** 通过，日志 `artifacts/guard-physical-safety/test-shortcut-transaction-plan.log`。新增用例核验同一 Prepared 清单包含发布与退役动作，并与原备份 transactionId/路径一一绑定。此前暂存发布测试最终为 **9/9**。未改运行期二进制，无需重复控制/硬件回归。

Prepared 仅表示修改前证据已持久化，不表示事务已提交或回退完成。目前仍缺组级完成/失败凭据、恢复执行器及与 Current 槽位切换事务的绑定；不能把 Prepared 当成功标志。未部署现场。

## 快捷方式组发布凭据

新增 Complete-ShortcutTransaction：逐项验证备份记录与计划的 transactionId/路径对应、Retire 目标已不存在、Publish 目标与创建回执的 SHA256 相同，随后 CreateNew 写入并刷新 `published.json`。其状态严格命名为 ShortcutsPublished，包含计划文件 SHA256 和记录数，不表示程序槽位或整包安装成功。Prepared 计划保持不变。

隔离 COM 测试 **11/11** 通过，日志 `artifacts/guard-physical-safety/test-shortcut-transaction-completion.log`；新增组发布凭据与计划绑定验证，修改入口后再次完成检查会拒绝，不覆盖既有完成凭据。差异格式检查通过。

完成凭据是当时的验证记录，不证明入口未来一直未被修改。仍未实现失败回滚、崩溃中断恢复、原文件备份二次完整性审查或与 Current 安装事务绑定。未触碰真实桌面或现场程序。

完成检查现补充原备份二次校验：严格检查清单版本、布尔存在状态、安装根绑定；原文件存在时只接受固定 original.lnk 文件名、有效 SHA256 且备份字节匹配；原文件不存在时不允许夹带备份路径或哈希。隔离测试 **12/12** 通过（`artifacts/guard-physical-safety/test-shortcut-backup-integrity.log`），新增篡改临时夹具备份后必须拒绝完成检查的反例，并在 finally 恢复夹具原字节。实际自动回滚和槽位事务绑定仍未实现。

完成凭据现从一次读取的计划字节同时解析 JSON 和计算 SHA256，核验结束后确认磁盘计划仍为该哈希，防止先验证旧计划、后记录新计划哈希。原 **12/12** 隔离用例复跑通过（`test-shortcut-plan-snapshot.log`）；新增在最终计划哈希读取前注入计划变化、必须报 ShortcutPlanChangedDuringCompletion 的定向反例，日志 `test-shortcut-plan-snapshot-injection.log`。注入只修改夹具计划并在 finally 恢复字节，不改现场文件。这仍不是整组文件系统事务或自动回滚实现。

## 恢复执行器隔离验证

新增 Restore-ShortcutTransaction，要求显式允许的目标路径，先核验整组计划、安装根、备份绑定及当前链接哈希，再恢复原文件。替换下来的链接和本次新增链接移入同目录唯一保留文件，不直接删除；原状态已恢复时重复调用不再修改。

PowerShell 7 隔离 COM 测试 **17/17** 通过，进程退出码 0，日志 `artifacts/guard-physical-safety/test-shortcut-rollback-executor.log`。新增覆盖用户已修改链接时整组预检拒绝、允许路径不完整时拒绝、被替换及退役的旧链接恢复原字节、重复回退不新增保留文件、原本不存在的新入口撤下并保留字节。仅操作 GUID 临时夹具，未运行安装器主入口或真实桌面。

执行器尚未与 Current 槽位回退联动，未处理跨账号/公共桌面、崩溃完成回执和重解析路径防护。最终哈希检查到 Replace/Move 之间仍有并发窗口；替换遇到变化会保留被替换字节并报错，不等于完全原子回退。以上局部通过不能作为完整部署回退验收。

## 快捷方式发布失败自动恢复接线

Install-Shortcuts 在 Prepared 计划落盘后的发布阶段增加异常处理：失败时调用同次计划的恢复执行器，恢复成功仍重新抛出原发布错误；恢复失败则同时报告发布错误、恢复错误和计划路径，禁止报告安装成功。该接线仅处理快捷方式函数内异常，不会回退 Current、服务或现场配置。

隔离 COM 测试 **18/18** 通过，退出码 0，日志 `artifacts/guard-physical-safety/test-shortcut-publication-failure-rollback.log`。新增实际 Install-Shortcuts 调用在完成发布后注入异常，验证自动恢复退役旧入口、撤下新增入口、保留无关入口并向调用者传播原错误。未执行安装器主入口。

尚有明确中断窗口：最终链接已发布但 created-link.json 未写成时，恢复执行器缺少新文件证据，会拒绝自动覆盖并报告双重错误。还需发布前持久化新链接证据、崩溃重入及整包事务设计；不能把这个异常处理称为完整安装回退。

## 发布前证据补齐

新增 prepared-link.json，在最终 Replace/Move 前以 CreateNew、Flush(true) 持久化目标路径、事务身份和已刷盘暂存链接的 SHA256，并读回校验。恢复时若 created-link.json 不存在，可使用此 Prepared 证据，但必须匹配同次事务与当前文件哈希；Prepared 本身不表示已发布。已有但损坏的 created 回执仍拒绝恢复，不自动忽略。

隔离 COM 测试 **19/19** 通过，退出码 0，日志 `artifacts/guard-physical-safety/test-shortcut-prepared-publication.log`。新增在最终链接已发布、created 回执尚未写入时抛错，验证实际 Install-Shortcuts 异常处理能依据预写证据恢复旧入口并撤下新入口。此测试覆盖可捕获异常，不代表进程被强杀、断电重启后的自动发现与重入已实现；整包事务、跨账号和并发窗口仍待处理。未部署现场。
