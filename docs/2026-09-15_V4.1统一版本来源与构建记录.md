# V4.1 统一版本来源与构建记录

## 版本身份

2026-09-15 成功执行 `git fetch origin --tags`；检查全部本地分支、已获取远端引用和标签，并对全部可见历史的 csproj、AssemblyInfo.cs、Version.props 执行 `git log --all -G '4[.]1[.]0[.]0'`，没有发现此前产品版本声明使用 4.1.0.0。文档和测试夹具此前已提及目标版本，不等于已发布产品版本。本轮选择 4.1.0.0，尚未创建候选 tag。

`ProductVersion.props` 是新的产品版本声明来源。`Directory.Build.props` 导入它；`Directory.Build.targets` 为以下九个组件生成 AssemblyVersion、AssemblyFileVersion、AssemblyInformationalVersion；原 AssemblyInfo.cs 不再分别维护版本数字。

- MTTFTest 主程序、Controller。
- FallbackGuard、Watchdog.Protocol、Watchdog.Client。
- Watchdog、SessionAgent、SafetyHardware、SafetyAgent。

主程序 ApplicationVersion 引用同一属性，Build-Release.ps1 直接读取同一 props。快捷方式既有实现继续读取实际主程序 FileVersion。其他独立工具和第三方库的版本不在这九个产品组件范围内。

`msbuild TfTest.sln /p:Configuration=Debug /p:Platform=x86 /m` 已通过，exit 0。逐一检查上述九个实际输出文件，AssemblyName.Version、FileVersion、ProductVersion 均为 4.1.0.0。
