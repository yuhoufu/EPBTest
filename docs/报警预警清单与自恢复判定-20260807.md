# EPB 预报警、报警条件与自恢复判定

> 审查日期：2026-08-07
> 审查对象：`V2.11.0.8` 源码与 `MTTfTest/Config` 运行配置
> 更新说明：已纳入《不可自恢复卡钳报警判定与持久禁用方案-20260807》的代码整改
> 当前正式模式：`EpbControlMode=AdaptiveCurrent`，EPB1～EPB12 全部启用严格完整曲线控制；旧 `LegacyFixedTiming` 路径不属于当前允许启动的正式试验路径。

## 1. 结论先行

1. 当前代码不是“出现报警后全部锁死”，而是分为三类：
   - **软预警**：继续本圈或安全作废本圈后自动重试；不点亮正式报警灯。
   - **系统/软件故障**：先断电隔离受影响通道或设备组，再自动恢复；通常不进入正式报警链。
   - **正式报警**：点亮通道报警灯、触发蜂鸣器、停止通道并保存报警证据。
2. **升级为正式报警后仍可能自动恢复，但客户确认的四类卡钳故障除外。** 空载区无爬坡、电流接近0、低平台8圈、峰值超过目标2A达8圈均使用 `NonRecoverableDisableChannel`，报警后持久取消当前项目启用。
3. 下列硬件锁存类 **不会自动恢复**：
   - 电机输出/断电命令失败；
   - 断电后电流未清零；
   - 程控电源 `ProtectionTrip`；
   - 支路高电流平台同时有新鲜的共享电源限流/低压/保护证据（`SharedPowerLimiting`）；
   - DAQ 设备缺失且连续两次独立枚举/自检均确认失败；
   - 液压释放超时，或连续三代新鲜压力证据确认无法建压/保压；
   - 启动定位过流同时有新鲜独立电源异常证据，或启动定位无法安全断电。
4. “自恢复=是”均为**有条件恢复**：任何 DAQ、电源、机械释放、启动定位或资格圈复核失败，都会保持隔离/报警，或继续有界退避自维护，不能理解为无条件重新上电。

## 3. 预报警清单

### 3.1 会进入通道预警/UI与预警快照的项目

| 预警/代码 | 触发条件 | 未升级时动作 | 升级条件 | 升级后是否自恢复 |
|---|---|---|---|---|
| `ForwardPeakOvershootWarning` 正向峰值过冲预警 | 完整峰值有效，`Peak-Target > 0.8 A` | 本圈继续反向释放；修正下一圈提前断电模型 | 只有完整峰值≥`Target+2.0 A`才累计，连续8个完整提交圈 | **否**。第8圈提交后锁存并持久禁用 |

| `RecoverableControlFaultWarning` 普通可恢复控制预警 | 非立即电流硬故障、非已带连续确认、非硬件锁存故障；同通道同码第 1～2 个不同尝试圈 | 安全断电、当前尝试圈作废、机械释放后自动重试 | 第3个连续尝试圈 | 通常**是（有条件）**；`ForwardLoadRiseNotStarted`、`OpenCircuitOrOutputFault`确认后例外，均不可恢复并持久禁用 |

| `ForwardSoftLimit` | 正向时间超过稳定模型的 `中位数 + max(1000 ms,4×MAD)` | 只记软预警，硬上限仍继续保护 | **本预警自身不升级** | 不适用 |
| `ClampReachedNearTargetPlateau` | 正向峰值已达到合格下限14.2 A、但仍低于15 A，且约200 ms窗口内上升斜率≤0.001 A/ms | 立即停止正向供电，按夹紧可接受继续反向释放 | 不升级 | 不适用 |
| 正向峰值偏低（普通欠调） | 有效峰值 `<Target-0.8 A`，但未形成低斜率平台停滞 | 预警并让模型自动减小提前量 | **本项自身不升级**；若形成低平台停滞则走上面的8圈规则 | 不适用 |
| 模型连续偏差预警 | 稳定模型形成后，正向夹紧时间或反向释放时间相对原中位数偏差>30%，连续≥3个成功圈 | 预警并继续以最近30个有效样本渐进更新模型 | 不升级 | 不适用 |

## 4. 正式报警清单与恢复判定

### 4.1 通道电流/曲线类

| 报警码/原因 | 条件 | 是否需要连续确认 | 报警后自动恢复 |
|---|---|---:|---|
| `ForwardFastOverCurrentCutoff` | 快速路径连续3个样本达到`Target+3.0 A` | 立即断正向电，但本身不是永久报警 | 不适用；随后以完整速率峰值按`Target+2.0 A`规则累计 |
| `ForwardPeakOvershoot2AConfirmed` | 有效完整峰值`≥Target+2.0 A`连续8个完整提交圈 | 8圈 | **否**；持久禁用当前项目通道 |
| `PeakEvidenceMismatch` | 有效、新鲜的快速/完整峰值偏差 >1.0 A 连续 3 圈 | 3圈 | **是（有条件）** |
| `ForwardLowPlateauConfirmed` | 低于14.2 A的低斜率高负载平台连续8个完整提交圈 | 8圈 | **否**；持久禁用当前项目通道 |
| `AbnormalHighCurrentPlateau` | 电流平台稳定约200 ms、带宽≤0.75 A、斜率接近0，且平台超过方向对应的异常高阈值 | 否，立即 | **是（有条件）**；若同时存在新鲜电源限流/低压/保护证据，升级为组级 `SharedPowerLimiting`，不自动恢复 |
| `OpenCircuitOrOutputFault` | 忽略涌流后电流 `≤0.10 A` 持续 200 ms | 连续3个尝试圈 | **否**；持久禁用当前项目通道 |
| `CurveSequenceInvalid` | 仍处于空行程阶段时电流已达到正向目标，曲线阶段顺序不可信 | 普通故障连续3个尝试圈 | **是（有条件）** |
| `ForwardLoadRiseNotStarted` | 排除近零后，到正向进展期限仍未检测到负载上升 | 连续3个尝试圈 | **否**；持久禁用当前项目通道 |
| `AbnormalLoadRiseDrop` | 负载上升峰值回落≥2.0 A、仍低于目标，并持续100 ms | 快速信号相关；非确认电源硬件时进入通道报警恢复 | **是（有条件）** |
| `ReverseCurrentDecayStalled` | 到反向进展期限后，P10仍高于释放阈值且下降斜率不足 | 普通故障连续3个尝试圈 | **是（有条件）** |
| `ForwardAbsoluteOnTimeExceeded` | 当前配置下正向上电达到6 s仍未结束 | 普通故障连续3个尝试圈 | **是（有条件）** |
| `ReverseAbsoluteOnTimeExceeded` | 当前配置下反向上电达到3.5 s仍未结束 | 普通故障连续3个尝试圈 | **是（有条件）** |
| `ForwardEndedWithoutClamp` / `ReverseEndedWithoutRelease` | 状态机结束但未得到夹紧/释放终态 | 普通故障连续3个尝试圈 | **是（有条件）** |
| `PeakCaptureInvalid` | 完整峰值捕获令牌/数据不匹配或无有效峰值 | 普通故障连续3个尝试圈 | **是（有条件）** |
| `UnhandledException` | 未分类且不能归入安全软件自愈的运行异常 | 普通故障连续3个尝试圈；若包含输出命令失败则硬件锁存 | 普通异常：**是**；输出命令失败：**否** |

可恢复的普通通道报警仍执行：停止并封存报警圈 → 自动调用恢复入口 → DAQ预检 → 电源预检 → 启动定位 → 2圈资格复核 → 按未来公共节律槽重新加入。上述四类 `NonRecoverableDisableChannel` 不进入此入口。

### 4.2 断电执行与断电电流类

| 报警/故障 | 条件 | 自动恢复 |
|---|---|---|
| `EpbOutputCommandFailed` / `OutputCommandFailed` | 正向、反向或关闭输出命令返回失败 | **否**；属于硬件锁存/联锁，需实时故障排除后人工重新开始 |
| `TerminalOffCommandFailed` | 夹紧、释放或硬故障终态的高优先级断电失败 | **否**；立即扩大到共享电源组联锁 |
| `SoftwareRecoveryOffFailed` | 软件自愈前无法保证通道断电 | **否**；禁止以“软件自愈”继续 |
| `OffCurrentNotCleared` | 高优先级断电后，在1 s窗口内新鲜电流仍高于有效清零阈值 | **否**；立即共享电源组联锁 |
| `OffCurrentUnverifiableDaqStale` | 断电验证窗口结束时没有新鲜DAQ样本，不能证明电流已清零 | 按DAQ派生故障处理：整组断电并自动恢复；同码连续3次可发正式报警，**仍会继续自恢复** |
| `OffCurrentVerificationFailed` | 断电电流验证过程抛异常 | 立即电源组失效安全关闭；当前故障码不在硬件锁存字符串白名单内，正式报警仍受普通3次确认约束。组内不会直接重新上电，需后续恢复/重新开始 |

### 4.3 DAQ/采集与落盘类

下列代码都先按软件/系统故障处理：`DaqSampleStale`、`DaqCallbackStale`、`ControlEnqueueStale`、`ControlProcessingStale`、`ControlLatencyExceeded`、`ControlQueueFull`、`BackgroundQueueFull`、`RawPersistenceQueueFull`、`DaqPersistenceQueueFull`、`DaqPersistenceLag`、`DaqClockModelInvalid`、`DaqCallbackException`、`ControlProducerReentry`、`ControlSequenceDiscontinuity`、`ControlBatchDuplicate`、`ControlBatchOutOfOrder`、`ControlMonotonicTickInvalid`、`FastPathFilterStateInvalid`、`ActiveCycleDataLimitExceeded`。

统一处置：受影响 DAQ 设备映射的通道立即断电、作废当前圈、不增加正式次数；健康 DAQ 组继续运行。软件恢复按 1/2/5/10/30 s 有界退避，60 s 未提交时执行受影响液压组 Stop→Start 等价清场。

| 最终状态 | 正式报警 | 自动恢复 |
|---|---|---|
| 运行圈 `DaqSampleStale` 归因后的第1～2次同码重复 | 否，通道预警/恢复状态 | **是** |
| 运行圈 `DaqSampleStale` 归因后的第3次同码重复 | 对首发通道发“确认可恢复报警”并点灯 | **是**；报警与恢复并行，恢复成功后重新加入 |
| 设备层直接上报的队列、时钟、回调、批次身份、滤波或持久化故障 | 不使用上述3次正式报警计数；直接进入DAQ组恢复/诊断状态 | **是** |
| 一般恢复超时、队列持续拥塞、时钟模型持续无效 | 不得仅凭软件失败升级为硬件报警 | **是，持续自维护**；必要时组级等价清场 |
| `DaqDeviceMissing`，且两次间隔约500 ms的独立 NI-DAQmx 枚举/自检均确认失败 | `DaqHardwareConfirmed`，DAQ组正式硬件报警 | **否** |

### 4.4 液压类

| 报警/故障 | 条件 | 分类与升级 | 自动恢复 |
|---|---|---|---|
| `PressureSampleUnavailable` | 无压力样本、样本无效或陈旧 | 系统故障，不作为液压硬件证据 | **是**，组内自愈 |
| `HydraulicBarrierTimeout` | 同液压代次的成员同步等待超过配置；当前 `BarrierTimeoutMs=0` 时使用试验周期10 s | 系统故障 | **是**，组内自愈 |
| `HydraulicBuildTimeout`（样本缺失/陈旧、已在容差内但未稳定） | 5 s内未完成200 ms稳定建压，但证据不能证明硬件低压 | 系统故障 | **是** |
| `HydraulicBuildTimeout`（新鲜压力持续低于90 bar） | 单代失败先系统自愈；连续3个液压代次失败后硬件确认 | 第3代正式组报警 | **否** |
| `HydraulicBuildTimeout`（新鲜压力持续高于110 bar） | 5 s内一直位于目标容差窗上方 | 当前分类器直接按硬件确认，不走“连续3代低压”计数 | **否** |
| `HydraulicPressureLost` | 已建压后压力低于有效保压下限并持续1 s | 连续3个液压代次确认后硬件报警；样本无效/陈旧不计硬件连续数 | 第1～2代：**是**；第3代报警后：**否** |
| `HydraulicReleaseTimeout` | 释压输出执行后5 s内未达到≤5 bar并稳定100 ms，或压力样本陈旧导致无法确认安全释压 | 立即硬件确认 | **否** |
| `HydraulicOperationCanceled` | 暂停、停止、DAQ自愈导致正常取消 | 软件瞬态，不发布硬件报警 | 不适用/随上层流程恢复 |

液压系统类恢复若60 s仍不能完成，会执行受影响液压组等价 Stop→Start 清场；该动作仍不是把软件故障伪装成硬件报警。

### 4.5 程控电源类

| 报警/故障 | 条件 | 分类 | 自动恢复 |
|---|---|---|---|
| `TelemetryStale` | 遥测时间戳或通信成功间隔超过500 ms | 系统故障 | **是**，电源组断电、重连、预检、机械释放后重入 |
| `UnexpectedOutputOff` | 运行期预期输出ON、无计划切换，但实时回读为OFF | 系统故障 | **是** |
| `SustainedCurrentLimit` | CC/限流/限功率持续≥300 ms | 系统故障 | **是**；若同时由支路高电流平台触发 `SharedPowerLimiting` 则转硬件报警 |
| `SustainedLowVoltage` | 输出电压低于6 V持续≥300 ms | 系统故障 | **是**；同上存在组合证据例外 |
| `ProtectionTrip` | 新鲜遥测明确 `ProtectionTripped=true` | 硬件确认，整电气组报警 | **否**；软件自愈中若再次确认保护仍触发，也立即转此报警 |
| `SharedPowerLimiting` | 通道出现立即电流硬故障/异常高平台，同时电源有新鲜保护、限流、低压或≥90%额定电流证据 | 硬件确认，整电气组报警 | **否** |
| `OutputOffUnverified` | 电源关闭后未能可靠回读确认OFF | 系统故障 | **是（有条件）**；进入组内自愈，但在关闭、重连和实时预检通过前不得带电重入 |

### 4.6 启动定位类

启动定位失败默认不是报警，而是安全断电后按 1/2/5/10/30 s 退避持续重试。只有以下两种组合进入正式报警：

| 条件 | 自动恢复 |
|---|---|
| 启动定位过流，并且同时取得新鲜独立电源异常证据 | **否** |
| `StartupPositioningOutputOffCommandFailed`，即定位异常/重试前无法执行安全断电 | **否** |

其他定位结果（`ForwardPositioningFault/Timeout`、`ReverseReleaseFault/Timeout`、`DaqSampleStale`、`FastPathSignalInvalid`、`InvalidCurrentSample`、普通异常）在能够安全断电时均按软件瞬态持续重试，不直接点正式报警灯。

## 5. 报警输出、快照与清除

- 任一活动正式通道报警会点亮该 EPB 对应 M-7055D 输出；配置允许时，蜂鸣器延迟200 ms去抖后鸣响。
- 报警快照默认保存最近10圈，包含当前运行圈；同一报警源快照冷却2 s，断电后继续保留1 s电流/压力尾部。
- 快照导出和报警串口均为尽力策略；失败会记录日志，但不得阻塞优先断电。
- 普通通道报警自动恢复成功后会后台重试清除报警灯；硬件锁存类不会自动清灯。
- 人工“重新开始”不再由旧故障码永久禁止，但必须重新经过实时 DAQ、电源、定位和资格复核；故障仍存在时会再次停止。

## 6. “升级后是否自恢复”汇总

| 类别 | 升级为正式报警后 |
|---|---|
| 空载区无爬坡、电流接近0、低平台8圈、峰值超过目标2A达8圈 | **自动恢复：否；当前项目持久禁用** |
| 峰值证据偏差、其它普通曲线/时序故障 | **自动恢复：是（有条件）** |
| 运行圈 DAQ样本陈旧根因连续3次的确认可恢复报警 | **自动恢复：是（有条件）** |
| 快速过流、异常高电流平台（没有共享电源硬证据） | **自动恢复：是（有条件）** |
| 输出/断电命令失败、断电电流未清零 | **自动恢复：否** |
| DAQ两次独立硬件探测确认失败 | **自动恢复：否** |
| 液压释放超时、连续3代新鲜低压证据 | **自动恢复：否** |
| 程控电源保护跳闸、共享电源组合硬证据 | **自动恢复：否** |
| 启动定位硬件双证据或无法安全断电 | **自动恢复：否** |

## 7. V2.11.0.8 已关闭的语义风险

### 7.1 快速断电与永久报警已分离

正向三样本达到`Target+3.0 A`时只生成`ForwardFastOverCurrentCutoff`并断电，永久报警只能由完整峰值证据在正式圈提交后累计，快速信号毛刺或证据不可用不能增加8圈连续数。

### 7.2 四类报警不再经过自动恢复入口

`ControlFault` 已增加结构化 `RecoveryPolicy`。四类客户确认故障固定为`NonRecoverableDisableChannel`，报警快照后执行项目禁用，不再调用`ResumeAlarmStoppedChannelAsync`；其它普通报警仍可按既有策略自动复核。
