## 一、升级只需要五步

### 第一步：退出旧程序

在 V2.14.2.11 中：

1. 停止试验；
2. 确认电机和电源已经关闭；
3. 等待数据保存完成；
4. 正常退出主程序。

本次升级不要运行旧版的 `一键卸载.cmd`。

### 第二步：解压 V2.15.0.0 操作员包

把整个 `.7z` 文件复制到测试机本地磁盘，然后完整解压。

不要直接在压缩包、U 盘或网络共享中运行。

解压后第一层应该看到：

```text
一键安装正式版.cmd
一键修复.cmd
一键卸载.cmd
检查运行状态.cmd
启动试验.cmd
快捷部署说明.md
QuickDeploy-Installer.ps1
Package\
```

`Package` 是已经校验的 V2.15.0.0 正式程序，不要修改或单独复制里面的 DLL。

### 第三步：双击安装

双击：

```text
一键安装正式版.cmd
```

Windows 弹出管理员权限提示时选择“是”。脚本会自动：

- 保留现场配置；
- 封存 V2.14.2.11 的旧恢复状态；
- 安装 V2.15.0.0；
- 安装 Supervisor 服务；
- 配置 SessionAgent 和登录自动启动；
- 创建桌面快捷方式。

看到“操作成功”和版本 `V2.15.0.0` 后，安装完成。

### 第四步：启动程序

双击解压目录中的：

```text
启动试验.cmd
```

也可以双击桌面的：

```text
MT EPB 试验系统 V2.15
```

不要直接双击安装目录中的 `MTTFTest.exe`。V2.15 必须由 Supervisor 签发启动许可，直接运行主程序会被拒绝。

### 第五步：检查运行状态

双击：

```text
检查运行状态.cmd
```

正常状态应包含：

```text
Supervisor service: Running
SessionAgent task: Running 或 Ready
AutoStart task: Ready 或 Running
```

进程列表中只应有一个 `MTTFTest` 主程序，路径应位于：

```text
C:\Program Files (x86)\MTTFTest\Current
```

## 二、五个脚本分别做什么

| 文件 | 什么时候使用 |
|---|---|
| `一键安装正式版.cmd` | 首次安装或从旧版本升级 |
| `启动试验.cmd` | 手工启动程序 |
| `检查运行状态.cmd` | 查看服务、任务和进程是否正常 |
| `一键修复.cmd` | V2.15 服务、任务或快捷方式损坏时使用 |
| `一键卸载.cmd` | 彻底移除软件时使用，正常升级不要使用 |

旧 V2.14.2.11 目录中的同名脚本只作为旧版本备份保留。升级后统一使用 V2.15.0.0 操作员包中的脚本。

## 三、以后更新版本怎么做

以后收到新版本时仍然是相同步骤：

1. 在旧程序中停止试验并正常退出；
2. 把新操作员包解压到一个新目录；
3. 双击新目录的 `一键安装正式版.cmd`；
4. 安装成功后运行 `启动试验.cmd`。

不要手工覆盖 `C:\Program Files (x86)\MTTFTest\Current`。

## 四、安装失败怎么办

如果安装窗口显示红色错误或没有出现“操作成功”：

1. 不要启动试验；
2. 保持设备断能；
3. 不要删除 `%LOCALAPPDATA%\MTTFTest`；
4. 不要修改 JSON 文件绕过检查；
5. 截图保存完整错误信息并交给研发分析。

如果提示旧会话缺少 `MotorOff`、`PressureSafe` 或 `PersistenceDrained` 安全证明，这是安装器主动阻止不安全升级，不是重新双击几次就能解决的问题。

安装结果保存在：

```text
C:\ProgramData\MTTFTest\DeploymentLogs\last-deployment-result.json
```
