# V2.13.0.28 DAQ 短空窗与自恢复阻断彻底整改计划

## 摘要

基于两份根因文档和当前未提交的 V2.13.0.27 修复继续迭代，不回退现有改动。目标是彻底切断：

`DAQ 短空窗 → 静态槽缺员 → 阶段身份丢失 → 活跃任务误判孤儿 → 30 秒反杀 → 看门狗丢失 RunId → 人工重启`

交付内容为 V2.13.0.28 源码、完整软件回归结果和新实施验收文档；本次不制作现场发布包、不提交 Git。

## 关键实现

### 1. DAQ 分级处置与公共槽

- 删除所有 `DaqSampleStale>100ms` 硬编码，配置默认值统一为：
  - Warn：250 ms
  - Suspect：1500 ms
  - Trip：5000 ms
- 修复当前配置读取时 `min=max` 导致参数不可调的问题；允许正数、严格递增的工程范围，启动日志和 checkpoint 记录最终生效值。
- 250 ms：
  - 未带电只限频记录；
  - 带电立即执行高优先级 DO OFF，作废当前动作并退出当前槽；
  - 不启动 DAQ、液压、整批或进程恢复。
- 1500 ms：
  - 建立按 `Device + RunId + Generation` 隔离的恢复栅栏；
  - 暂停该设备关联通道，完成稳定数据观察、供电检查和机械重新资格后才能加入未来槽；
  - 必须等该代次全部必需通道完成资格，不能由第一个通道提前清除设备栅栏。
- 5000 ms：
  - 连续监督轮询仍陈旧或 NI 明确报错时，仅重建对应 DAQ task；
  - 历史峰值已恢复时不得跨级触发。
- 正式公共槽改成“实际到达 + 300 ms admission window”：
  - 新增正式槽 `Join`、`SkipForSlot` 和 `Admitted` 结果；
  - DAQ 恢复、取消或资格未完成的通道明确跳过当前槽，不进入必须到达成员集；
  - 迟到通道只能加入下一槽，禁止使用未获准的液压 lease；
  - 学习和资格阶段继续使用完整固定成员，不使用动态窗口。
- 正式阶段某液压组失败只影响该组；已成功完成的健康组提交当前周期，不再因另一组缺员整体回退。
- 对 Join/Skip 并发、重复 Skip、窗口关闭时竞态采用幂等状态转换，确保屏障一定收敛。

### 2. 恢复身份、任务覆盖与进展续租

- 新增不可变 `HydraulicRecoveryIntent`，固定保存：
  `SourcePhase、OwnerKind、TargetPhase、RunId、RunEpoch、IncidentId、OwnerId、HydraulicId、Channels`。
- 明确阶段映射：
  - PreRelease、SingleChannel → Startup
  - Learning → Learning
  - Qualification → Qualification
  - Formal → Formal
- `Recovery` 只表示新的执行代次，禁止作为业务来源阶段；所有旧调用改为显式传递原始阶段，无法映射时直接暴露编程错误，不再默认 Startup。
- 恢复任务登记项保存完整 incident/owner/target 身份；覆盖判断必须精确匹配 RunEpoch、IncidentId、OwnerId 和通道。
- `TaskCovered=true` 一律视为有效执行覆盖：
  - owner 投影短暂不一致时记录 `MetadataMismatch` 并从不可变任务契约自修复；
  - 不得产生 Orphan、终态清场或外部恢复。
- 孤儿成立必须同时满足：
  - 无精确匹配活跃任务；
  - 无有效 owner；
  - progress token 至少 10 秒未变化；
  - 连续复查后仍成立。
- StopAll、DAQ 重建、液压释放/建压、每个学习圈、资格完成和正式定时器提交都刷新材料进展。
- 删除固定 30 秒进程内恢复反杀：
  - StopAll 保留 30 秒物理安全期限；
  - DAQ 重建阶段 60 秒；
  - 学习按通道数使用最长 3 分钟阶段期限；
  - 连续 60 秒无材料进展或总恢复时间达到 300 秒才允许外部接管。
- 外部接管前先取消恢复 worker，等待有界安全清场，再撤销 permit；不得在学习动作中途直接断权并把派生的 `PermitMissing` 计为硬件失败。
- 液压、电源恢复请求按组合并到唯一 owner；移除通道级与组级嵌套的 3×3 重试风暴，软件重试使用有上限退避并受 progress lease 管理。
- `ExpectedOutputDisabled` 表示等待唯一电源恢复 owner，不计入定位或学习失败次数。

### 3. 看门狗恢复证据与冗余断电证明

- Watchdog journal 增加可向后兼容的 `LastVerifiedActiveRun`：
  - 只接受身份校验通过、RunId 非空、RunActive=true 的 InitialProcess 心跳；
  - 保存 RunId/Epoch、PID/启动时间、所选通道、恢复资格、完成/人工/永久隔离列表、心跳序号以及匹配 checkpoint 身份；
  - RunId、通道意图或 checkpoint 身份变化时同步持久化。
- StopAll、清场后的空 RunId，以及 recovery child/idle 心跳不得覆盖最后有效活动运行。
- 首次拉起按以下顺序恢复意图：
  1. `LastVerifiedActiveRun`
  2. 最后有效活动心跳
  3. 身份匹配且已 Armed 的 checkpoint mirror
- 冻结排除列表只包含人工排除、已完成和有权威证据的永久硬件隔离；DAQ/学习等瞬态隔离不得污染恢复意图。
- 全部通道已完成时正常解除 armed；全部确认为永久硬件故障时保持安全 idle；只有 exe/hash/PID 或 checkpoint 身份冲突、输出无法证明安全时才阻止拉起。
- 保留现有进程身份校验、程序 hash、最大上电时间、DO OFF 高优先级路径和重启预算。
- 实现配置化冗余断电矩阵：
  - `EpbPowerSupplyOffProofThresholdA=0.5`
  - `EpbPowerSupplyOffProofMaxAgeMs=1000`
  - DO OFF 成功且 DAQ 新鲜低电流：确认断电；
  - DAQ 陈旧但电源遥测新鲜且组电流 ≤0.5 A：确认断电，不触发电源组联锁；
  - DO 失败、两类遥测均不可用或新鲜电流仍高：关闭关联电源组。
- 电源应急 latch 增加 incident/generation 身份，旧恢复事务不得清除新事务建立的 latch。

## 接口与版本

- 新增配置：
  `GlobalFormalSlotAdmissionWindowMs=300`、`RecoveryOrphanGraceMs=10000`、`InProcessRecoveryNoProgressMs=60000`、`InProcessRecoveryMaxTotalMs=300000` 以及上述断电证明参数。
- 状态机接收统一 DAQ 有效阈值；正式槽协调器新增 Join/Skip 接口；恢复任务登记和 journal 使用新增不可变身份字段。
- 不改变外部 Watchdog 消息协议；journal 新字段采用可选字段兼容旧文件。
- 主程序、Watchdog Host、Client、Protocol 的 Assembly/File/Informational Version，以及 ClickOnce ApplicationVersion 全部升级为 `2.13.0.28`；同步更新严格版本测试。

## 测试与验收

- DAQ 注入：
  - 134 ms 双设备 gap 不作废周期、不触发屏障或恢复；
  - 250 ms 带电时只 OFF 并作废当前动作；
  - 1500 ms 建立设备资格栅栏；
  - 5000 ms 连续成立后仅重建对应 DAQ task；
  - 恢复后的历史峰值不得再次升级。
- 公共槽：
  - EPB4 延迟超过 admission window 时，EPB5/11/12 不等待 15 秒；
  - 验证 Join/Skip/Cancel 并发、迟到、重复调用和下一槽重新加入；
  - 运行不少于 10,000 次合成竞态，不能死锁、泄漏 lease 或出现静态缺员。
- 恢复身份：
  - 覆盖 Startup、Learning、Qualification、Formal 的完整映射；
  - Recovery 作为来源必须被拒绝；
  - Formal 恢复运行超过 1 秒仍保持 Formal；
  - `TaskCovered=true + owner 暂缺` 只能自修复，绝不能 Orphan。
- 进展续租：
  - 学习超过 30 秒且持续完成机械圈时不得外部接管；
  - 60 秒无进展和 300 秒总期限按安全交接顺序升级；
  - permit 不得在活跃学习 worker 中途被撤销。
- Watchdog：
  - 重放“有效 RunId 心跳 → 清场空 RunId → 进程退出”，必须从持久快照首次自动拉起；
  - Watchdog 自身重启、recovery child 污染、checkpoint fallback、身份/hash 冲突和全部排除分支全部覆盖。
- 电源：
  - DAQ 陈旧 + DO OFF 成功 + 0 A 新鲜不得联锁；
  - DO 失败、遥测双陈旧、电流高于阈值必须关闭电源组；
  - 验证 latch 的旧 incident 不能清除新 incident。
- 执行并记录：
  - Debug x86 全量构建；
  - Release Any CPU 全量构建；
  - AdaptiveControlTests；
  - EpbDiskWriterTests；
  - PowerSupplyDebugger.Tests；
  - 版本身份、未观察任务、日志关键字和 Git diff 审核。
- 新建文档：
